Обновление Inbox Classic

Получите последнюю версию Inbox Classic.

Чтобы узнать свою версию, выберите Inbox Classic > О программе Inbox Classic.

Если автоматическая проверка включена, Inbox Classic периодически проверяет наличие новой версии. Для установки следуйте указаниям окна обновления. Чтобы проверить сейчас, выберите Inbox Classic > Проверить обновления.

Ваши учетные записи, почта и параметры сохраняются при обновлениях.
