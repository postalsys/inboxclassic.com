Подключение ИИ-агента

Разрешите ИИ-агенту, например Claude, читать вашу почту и управлять ею через Inbox Classic.

С вашей почтой может работать Claude, Cursor или другая программа с поддержкой Model Context Protocol (MCP). В самой Inbox Classic нет встроенного ИИ. Данные не передаются в службы ИИ, пока вы не разрешите агенту доступ.

Чтобы подключить агента:

  1. Откройте Сервис > ИИ-агенты и нажмите Как подключить агента. Inbox Classic покажет фрагмент конфигурации для настроек агента.
  2. Добавьте его в настройки серверов MCP вашего агента. В Claude Desktop откройте Settings > Developer > Edit Config.
  3. Запустите агента. При первом подключении Inbox Classic попросит выбрать разрешенные действия и доступные учетные записи.

Если Inbox Classic не запущена, агент запустит ее в фоновом режиме. Подключаться могут только программы, работающие под вашей учетной записью пользователя на этом компьютере.

Inbox Classic определяет через операционную систему, какая программа запустила агента. Агент не может получить разрешения другой программы, просто назвавшись ее именем. Если заявленное имя отличается, это будет указано в запросе на доступ. Такая проверка разделяет доступ ваших агентов, но не защищает от вредоносной программы, работающей под вашей учетной записью пользователя: она и так может прочитать вашу почту.

Агент может следить за изменениями почты во «Входящих», учетной записи или отдельной папке. Он также может предлагать два готовых запроса: «Triage my inbox» (разобрать входящие) и «Summarize unread» (составить сводку непрочитанных). При этом действуют выбранные вами разрешения, а прочитанные агентом сообщения и другие данные записываются в журнал.

Inbox Classic считает одной программой агентов, запущенных из одной и той же программы терминала, например Claude Code. Она один раз запрашивает доступ для программ, запущенных из терминала, и все они используют общие разрешения. Чтобы дать агенту отдельный доступ, добавьте в его настройках после --mcp параметр --name и любое имя, например "args": ["--mcp", "--name", "Claude Code"]. Тогда Inbox Classic будет запрашивать доступ для него под этим именем. Выбранное имя не подтверждает, какая это программа.

Чтобы запретить всем агентам доступ к почте, отключите параметр Разрешить ИИ-агентам подключаться к Inbox Classic в окне Сервис > ИИ-агенты.
