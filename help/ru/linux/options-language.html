Настройки

Выберите язык Inbox Classic, настройте отображение почты, уведомления и предварительную загрузку.

Выберите Главное меню > Параметры. Настройки разделены на три страницы: Общие, Чтение и Загрузка. Изменения вступают в силу сразу, кроме языка: он меняется после перезапуска Inbox Classic.

Общие

  • Параметр Язык определяет язык окон и справки: язык вашей системы или один из языков списка. Inbox Classic ищет поддерживаемый язык среди предпочитаемых языков системы. Если ни один не подходит, используется английский.
  • Параметр Уведомлять о новой почте включает уведомления о новой почте. Они не показываются, пока главное окно на переднем плане, и могут быть заблокированы системой. По умолчанию это включено.
  • Параметр Показывать коды для входа в уведомлениях о новой почте добавляет распознанный код для входа в уведомление, если проверка домена и условия показа кода выполнены. По умолчанию это выключено, так как уведомление можно прочитать на заблокированном экране. Пока уведомления выключены, этот параметр недоступен.
  • Параметр Задержка перед отправкой задерживает сообщение перед отправкой в папке «Исходящие» на несколько секунд, чтобы отправку еще можно было отменить. По умолчанию это 10 секунд.
  • Команда Сделать почтовой программой по умолчанию позволяет назначить Inbox Classic для почтовых ссылок, а Открывать файлы .eml в Inbox Classic для файлов сообщений. См. раздел Inbox Classic как почтовая программа по умолчанию.

Для смены языка нужен перезапуск Inbox Classic. Нажмите Перезапустить или Позже, чтобы язык сменился при следующем запуске.

Чтение

  • Параметр Макет определяет макет: автоматический по ширине окна, классический или со столбцами. См. раздел Макеты.
  • Параметр Группировать сообщения по беседам объединяет исходное сообщение и ответы на него в беседу. По умолчанию это включено.
  • Параметр Показывать изображения отправителей в списке сообщений показывает логотипы брендов, изображения контактов и инициалы в макете со столбцами. По умолчанию это включено.
  • Параметр Показывать сообщения на темном фоне, когда в системе включен темный режим показывает сообщения, которые вы читаете и пишете, на темном фоне, когда в системе включен темный режим. По умолчанию это включено.
  • Параметр Показывать вложения в сообщениях показывает изображения и первые страницы файлов PDF после текста сообщения. По умолчанию включено. Отключите Показывать PDF-файлы в сообщениях, чтобы оставить только изображения. См. раздел Вложения.
  • Параметр Загружать изображения во всех сообщениях включает автоматическую загрузку изображений, кроме сообщений в нежелательной почте. Для зашифрованных частей каждый раз требуется явное разрешение. По умолчанию параметр отключен: загрузка изображений может сообщить отправителю о прочтении. См. раздел Изображения и отслеживание.
  • Кнопка Надежные отправители открывает список отправителей, для которых разрешена автоматическая загрузка изображений при подтвержденном домене. Здесь можно удалить их из списка. Исключения для нежелательной и зашифрованной почты сохраняются.
  • Параметр Искать в зашифрованных сообщениях включает поиск по расшифрованным сообщениям. После загрузки Inbox Classic пытается расшифровать сообщения на этом компьютере с помощью доступных закрытых ключей. Если это удается, их текст и защищенные темы становятся доступны для поиска и списка сообщений. По умолчанию это включено. Расшифрованный текст и защищенные темы хранятся в локальном поисковом индексе без шифрования. Отключение параметра удаляет эти данные и возвращает внешние темы в список. ИИ-агенты не могут искать по расшифрованному содержимому.
  • Параметр Искать ключи на keys.openpgp.org разрешает поиск ключей на keys.openpgp.org. При поиске ключа получателя сначала проверяется его домен; серверу ключей передается адрес. При поиске ключа подписи передается отпечаток или идентификатор ключа. Поиск запускается при шифровании или по вашему запросу. По умолчанию это включено.

Загрузка

  • Параметр Загружать сообщения заранее определяет, какие сообщения загружаются до открытия: по умолчанию это недавние сообщения размером до 1 МБ каждое. См. раздел Предварительная загрузка сообщений.
  • Параметр Лимит места для сообщений на учетную запись задает целевой объем кеша содержимого для каждой учетной записи. По умолчанию это 1 ГБ. Черновики и сообщения, открытые после запуска, не удаляются, поэтому лимит может быть превышен.
