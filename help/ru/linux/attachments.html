Вложения

Открывайте или сохраняйте файлы, пришедшие в сообщении, и вкладывайте файлы в свои сообщения.

Изображения и файлы PDF в сообщении

После текста сообщения показываются изображения и до пяти страниц каждого файла PDF с именами и размерами файлов. Щелкните изображение или страницу, чтобы открыть файл. Для просмотра остальных страниц большого PDF есть ссылка на его открытие. Автоматически показывается до 20 изображений и страниц; под ними указано, сколько еще файлов есть в списке вложений.

Inbox Classic сама создает изображения для предварительного просмотра: код из файлов не запускается, данные из интернета не загружаются. Если предварительный просмотр недоступен, например для изображения HEIC или защищенного паролем PDF, вместо него показана плитка с именем файла, размером и причиной. Щелкните плитку, чтобы открыть файл. Пока вложения большого сообщения еще загружаются, вместо них тоже показаны плитки. В сообщении с цифровой подписью или шифрованием вложения каждой части находятся внутри ее рамки. Изображения для предварительного просмотра зашифрованной части хранятся только в памяти и удаляются при переходе к другому сообщению.

Чтобы включить или отключить предварительный просмотр файла в сообщении, щелкните его правой кнопкой мыши в списке вложений и выберите Показать в сообщении. Этот выбор действует, пока открыто сообщение.

Чтобы видеть только список вложений, отключите Показывать вложения в сообщениях в разделе Главное меню > Параметры > Чтение. Если Inbox Classic завершится во время создания предварительного просмотра файла, при следующем запуске просмотр PDF будет отключен и появится объяснение. Это не доказывает, что причиной остановки был файл. Включите Показывать PDF-файлы в сообщениях, чтобы снова просматривать PDF в сообщениях.

При печати сообщения показанные в нем изображения предварительного просмотра печатаются вместе с текстом. Для файлов PDF печатаются только их имена; сами файлы нужно печатать из программы для просмотра PDF. В сообщении с цифровой подписью или шифрованием изображения следуют за текстом своей части и снабжены ее названием.

Открытие вложения

Файлы сообщения перечислены под его заголовком, у каждого указаны имя и размер. Дважды щелкните файл, чтобы открыть его в программе, которую компьютер использует для таких файлов. Для работы с клавиатуры нажимайте Tab, чтобы перейти к списку файлов, выберите нужный клавишами со стрелками и нажмите Enter.

Щелкните файл правой кнопкой мыши, чтобы выбрать Открыть, Сохранить как или Сохранить все. Скрепка справа от заголовка тоже показывает список файлов.

Inbox Classic блокирует открытие распознанных типов файлов, способных запускать код: программ, сценариев, установщиков, ярлыков, образов дисков, веб-страниц и документов Office с макросами. Для них команда Открыть недоступна; сохраните такой файл и откройте его сами, только если доверяете его источнику.

Для открытия файла Inbox Classic сохраняет копию во временной папке вашей учетной записи пользователя. При запуске программа пытается удалить копии старше суток. В Windows и macOS файлы помечаются как полученные из интернета. Вложения из зашифрованных сообщений сохраняются там без шифрования; при первом открытии Inbox Classic предупреждает об этом.

Сохранение вложения

Щелкните файл правой кнопкой мыши и выберите Сохранить как или выберите Сохранить все, чтобы сохранить все файлы в папку. Inbox Classic предлагает безопасное имя, без символов, способных исказить отображение имени. При сохранении всех вложений существующий файл с таким же именем сохраняется, а новый получает номер. При сохранении одного файла системное окно может предложить заменить существующий файл.

Открывайте вложения только от тех, от кого вы их ждете. Программа или документ, который просит «включить содержимое», может получить контроль над вашим компьютером. К программам относятся файлы .sh, .deb, .rpm, .AppImage и .desktop.

Вложение файла

Чтобы вложить файлы в сообщение, которое вы пишете:

  1. Нажмите Вложить.
  2. Выберите файлы. Они появятся в поле Вложения вместе с размерами файлов.

Можно также перетащить файлы из файлового менеджера на поля адресов. Файл, который не является изображением, можно перетащить и на текст.

Чтобы убрать файл, выделите его и нажмите Del или щелкните его правой кнопкой мыши и выберите Удалить. Файлы читаются при отправке сообщения, поэтому до тех пор не перемещайте их.
