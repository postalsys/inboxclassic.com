Gmail и Outlook.com

Для Gmail можно использовать вход через браузер или, если учетная запись это поддерживает, пароль приложения. Для Outlook.com и Microsoft 365 доступен только вход через браузер.

Google и Microsoft не разрешают почтовым программам использовать ваш обычный пароль. В Gmail можно войти через браузер или, если учетная запись это поддерживает, с паролем приложения. В Outlook.com и Microsoft 365 входите через браузер.

Вход через браузер

Нажмите Войти через Google или Войти через Microsoft в окне Добавить почтовую учетную запись. Вы вводите пароль на собственной странице Google или Microsoft, поэтому Inbox Classic его никогда не видит. Такая учетная запись всегда использует собственные почтовые серверы провайдера.

В организации с Microsoft 365 может потребоваться разрешение администратора на использование Inbox Classic. Тогда Microsoft показывает Need admin approval, а Inbox Classic сообщает адрес, по которому администратор может дать разрешение.

Кнопка Войти через Google в этой сборке по умолчанию отключена. Если приложение Google находится в режиме тестирования, вход доступен только добавленным в него тестовым пользователям. Используйте пароль приложения, если учетная запись это поддерживает, или собственное приложение для входа (см. раздел Приложения для входа).

Пароль приложения

  1. Для Gmail создайте пароль приложения в учетной записи Google, в разделе Безопасность > Двухэтапная аутентификация > Пароли приложений. Для этого нужна двухэтапная аутентификация, а учетная запись должна поддерживать пароли приложений.
  2. В окне Добавить почтовую учетную запись введите имя и адрес и нажмите Далее >.
  3. Если появится выбор способа входа, нажмите Использовать пароль приложения.
  4. Введите пароль приложения в поле Пароль и нажмите Готово.

Когда сеанс входа завершается

Если Google или Microsoft завершает сеанс, Inbox Classic сообщает «Вход в учетную запись „…“ отклонен или срок действия сеанса истек.» и спрашивает, войти ли снова через браузер. Выберите Да и войдите еще раз.
