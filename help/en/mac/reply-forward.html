Reply and forward

Answer the sender or everyone, or send a message on to someone else.

  • Reply (⌘R) answers the sender.
  • Reply All (⇧⌘R) answers everyone the message went to.
  • Forward (⇧⌘F) sends the message on. You type the recipients.

A reply or forward goes from the account the original message is in.

The original message

In a reply, the original message is folded away behind a ••• button under your text, so you see only what you write. It is sent with your answer either way. To shorten it, click the button, or select all with ⌘A: the original then becomes part of your text.

In a forward, the original is in the text from the start, since it is what you send.

A reply follows the original’s format. A reply to a plain text message is plain text, with the original quoted with >, unless you format something.

Forward several messages

Select several messages and click Forward. One new message is written with all of them attached as .eml files. Its subject is the first message’s.
