Save, print and import messages

Save messages as files, open and bring in message files, print a message and see its headers and source.

Save messages as files

Choose File > Save As (⇧⌘S) to save the message shown as an .eml file, which other mail programs open. With several messages selected, it asks for a folder and saves each one there, named after its subject. A file already there is never replaced.

You can also drag messages from the list to the desktop or to a folder in the Finder.

Import message files

Select a folder and choose File > Import Messages, or drag .eml files onto a folder in the folder list. The messages are put in that folder, on the server too. A file that is not a message is not imported.

Open message files

Double-click an .eml file in the Finder, or right-click it and open it with Inbox Classic. It opens in a message window with Reply, Reply All, Forward, Print and Save As. If another app opens it, see Make Inbox Classic your mail app.

Print

  1. Choose File > Print (⌘P). A print preview opens.
  2. Choose the printer, the copies and the pages, or save as PDF.
  3. Click the print button. The message prints with its sender, date, recipients and subject.

Headers and source

File > Properties (⌥⌘U) shows the message’s Internet headers: who sent it, through which servers, and when. View > Message Source shows the whole message as text. Save As in that window saves it as an .eml file.
