Sort new mail with rules

Automatically move, mark as read, flag or archive incoming messages that meet your criteria.

A rule combines search criteria with actions to apply to matching messages as they arrive in your Inbox. For example, a rule with from:news@example.com can move newsletters from that address to a separate folder and mark them as read.

To make a rule:

  1. Choose Tools > Message Rules, then click New.
  2. Enter a name and fill in Search criteria using the same terms as in the search box, such as from:, subject: or list:. The line below counts matching Inbox messages in the selected account, or all accounts if none is selected.
  3. Choose one or more actions for matching messages: move them to a folder, mark them as read, flag them, archive them, move them to Junk E-mail, delete them or suppress notifications.
  4. Click OK.

You can also create a rule from a message or a search. Choose Message > Create Rule from Message to fill in the selected message’s sender or mailing list. Click Create Rule above the search results to use your current search criteria.

How rules work

Rules process new Inbox arrivals while Inbox Classic is running, including when its main window is hidden. Existing messages are only affected if you check Also apply it to the messages already in the Inbox. Matching rules run in the order shown in the list. Once a rule schedules a valid move out of the Inbox, later rules are skipped for that message. Server processing can still fail. Clear a rule’s check box in the list to disable it without deleting it.

Changing rules

To edit a rule, select it in the list and click Edit, or double-click it. Use Move Up and Move Down to change the order, or Delete to delete the rule. In the rule editor, Show closes the editor without saving its changes and searches all Inboxes with the typed query. Unlike the match count, this search does not keep the account restriction.

Rules apply to new Inbox messages, so folder and date filters are not supported. If you use in:, before:, after:, older_than: or newer_than:, a message explains why these filters cannot be used. Rules cannot send messages or delete them permanently: Delete it moves them to Deleted Items only if that folder exists.

Rules run on this computer. To sort mail while it is off, use the filters of your mail provider.
