Drafts and the Outbox

Save a message to finish later, and see what waits to be sent.

Save a draft

Click Save, or press ⌘S. The message is kept in the account’s Drafts folder, on the server. Saving again replaces the earlier copy. The status bar of the message says when it was saved.

Closing a message with changes asks whether to save them:

  • Save saves it in Drafts.
  • Don’t Save throws the changes away.
  • Cancel goes back to the message.

To go on writing, double-click the draft in Drafts. It opens with its recipients, text and files. Once it is sent, the draft is removed.

A message you write is a window of its own, so you can read mail while it stays open. Closing Inbox Classic first closes the messages you are writing, asking about those with changes.

The Outbox

Send puts the message in the Outbox and sends it right away. The status bar of the main window says when it is sent.

When a message cannot go, for example without a connection, it stays in the Outbox. It goes with the next check for mail, so nothing you wrote is lost.

To see what waits, choose Tools > Outbox. It lists each message with why it did not go. Send All Now tries again at once, and you can delete a message there too.
