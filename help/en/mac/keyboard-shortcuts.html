In the message list

KeysDoes
↑ ↓Select the message above or below
⇧+↑ ⇧+↓Add the message above or below to the selection
⌘+ClickAdd a message to the selection, or take it out
⇧+ClickSelect every message from the selected one to this one
↩Open the message in a window of its own
→ ←Show or hide the other messages of a conversation
NGo to the next unread message
AArchive the message
WWatch the conversation
KIgnore the conversation
TabMove between the folder list, the message list and the reading pane
EscEnd a search and show the folder again

While you write

KeysDoes
⌘BBold
⌘IItalic
⌘UUnderline
⌘KAdd a link, or change the link at the cursor
⌘+ClickOpen a link in your browser
⌘ASelect all, the folded original message of a reply included
⌘SSave the message in Drafts
⌘ReturnSend the message

In the list of addresses as you type

KeysDoes
↑ ↓Choose a person
↩ or TabTake the chosen person
EscClose the list

In the Address Book

KeysDoes
⌫Delete the selected contacts, or the selected group, after asking
EscClose a contact or group without saving
Search words Read messages Write a message
