Attachments

Open or save files attached to a message, and attach files to messages you write.

See pictures and PDF files in the message

Picture previews and up to five pages of each PDF appear after the message text, with their names and sizes. Click one to open the file. A longer PDF file has a link that opens it. Up to 20 pictures and pages appear automatically; a line below them counts the other files.

These are copies that Inbox Classic draws itself: nothing in a file runs, and nothing is loaded from the internet. A file it cannot draw shows as a tile with its name, its size and the reason, for example a HEIC picture or a PDF file protected by a password; click the tile to open the file. While a large message is still downloading, its files show as tiles until they arrive. In a signed or encrypted message, each part shows its own files inside its own frame. Previews from encrypted parts stay in memory rather than in preview files. Opening or saving an attachment separately writes an unencrypted copy.

To show a file in the message, or to take it out, right-click it in the list of files and choose Show in Message. This lasts while the message is shown.

To see only the list, turn off Show attachments in messages in Inbox Classic > Settings > Reading. If Inbox Classic stops while rendering a file preview, it disables PDF previews at the next start and explains this. This does not prove the file caused the interruption; turn on Show PDF files in messages to show them again.

When you print a message, the picture previews shown in it are printed too. PDF files are not: a line names each one, and you print it from its own program. In a signed or encrypted message, each part’s pictures come right after that part’s text, each named with its part.

Open an attachment

The files of a message are listed under its header, each with its name and size. Double-click a file to open it with the program your computer uses for it. With the keyboard, press Tab until the files are chosen, pick one with the arrow keys and press ↩.

Right-click a file for Open, Save As and Save All. The paper clip at the right of the header lists the files too.

Inbox Classic blocks opening recognized programs, scripts, installers, shortcuts, disk images, web pages and Office documents with macros. Their Open is off; save such a file, and open it yourself only if you trust where it comes from.

To open a file, Inbox Classic saves a copy in a temporary folder for your user account. At startup, the app tries to remove temporary copies more than a day old. On Windows and macOS, files are marked as coming from the internet. Attachments from encrypted messages are stored there without encryption; Inbox Classic explains this the first time you open one.

Save an attachment

Right-click a file and choose Save As, or choose Save All to save them all into a folder. Inbox Classic suggests a safe name, without characters that could make a name look like something else. When saving all attachments, existing files are kept and new files with the same names get numbers. Saving one file follows the system’s save dialog, which may offer to replace a file.

Open attachments only from people you expect them from. A program, or a document that asks you to “enable content”, can take over your computer. Programs include .app, .pkg, .dmg and .command files.

Attach a file

To attach files to the message you write:

  1. Click Attach.
  2. Choose the files. They are listed in Attachments with their sizes.

You can also drag files from the Finder onto the address fields. A file that is not a picture can also go onto the text.

To take a file off, select it and press ⌫, or right-click it and choose Remove. The files are read when the message is sent, so keep them where they are until then.
