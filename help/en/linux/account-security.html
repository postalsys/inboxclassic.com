Account security settings

The security settings of an account’s servers, and what each one means.

Each account has IMAP security for the incoming server and SMTP security for the outgoing one. Inbox Classic fills them in when it finds your provider’s settings. To change them, open the account’s properties in File > Accounts.

SettingMeaning
SSL/TLSThe connection is encrypted from the start. Usually port 993 for incoming mail and 465 for outgoing mail.
STARTTLSThe connection is encrypted right after it opens. Usually port 143 for incoming mail and 587 for outgoing mail. Inbox Classic stops if the server does not offer encryption.
None (unencrypted)Your password and mail travel readable by anyone on the network.
Use None (unencrypted) only for a server on your own computer or local network. Inbox Classic warns you before it uses it.

Inbox Classic checks that every server is the one it claims to be, against the certificates your system trusts. There is no switch to accept any certificate.

Your password is kept in your keyring, never in the mail store. An account that signs in through the browser keeps no password at all.
