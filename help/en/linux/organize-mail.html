Flag, archive and move messages

Flag messages, mark them as junk, archive them or move them to another folder, one or several at a time.

Select several messages

Use Ctrl+Click to add a message to the selection, or click the first and Shift+Click the last. Edit > Select All (Ctrl+A) selects every message of the list. The commands below then work on all of them.

Flag

Choose Message > Flag Message to flag a message or to take the flag away. To flag it in a color, choose Message > Flag and a color. Apple Mail shows the same colors. Clear Flag takes the flag away.

Junk

Click Junk, or press Ctrl+J, to move a message to Junk E-mail and tell your mail server it is junk. In Junk E-mail, Not Junk moves it back to the Inbox.

Archive

Click Archive, or press A in the message list, to move a message from the Inbox into Archive. If the account has no such folder, Inbox Classic makes it. On Gmail, archiving takes the message’s labels away, so it stays only in All Mail.

Move or copy

To move or copy messages to a folder:

  1. Right-click the messages and choose Move to Folder or Copy to Folder. Move to Folder is also in the Edit menu (Ctrl+Shift+V).
  2. Choose a folder of any account. Type part of a name to find it. The folders you used last are under Recent.
  3. Click Move or Copy.

You can also drag messages onto a folder in the folder list. Hold Ctrl as you let go to copy them instead. A message moved to another account is removed from its own server only after the copy has arrived.

All of this happens on the server too, so your other mail programs see it.
