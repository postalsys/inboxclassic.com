What an agent may do

Choose what each AI agent may do with your mail, and see and undo what it did.

The first time a program’s agent connects, Inbox Classic asks you, naming the program. Choose what it may do:

  • read mail: folders, the message list, search and messages
  • organize mail: read state, flags, junk, moving and deleting to Deleted Items
  • write drafts for you to send
  • send mail, each message only after you say yes

Then choose the accounts it may see, and click Allow. Don’t Allow turns the program away, and you are not asked about it again.

An agent never deletes anything for good and never changes your account settings. Reading a message does not mark it read. What it changes shows in the windows at once.

See and change access

Tools > AI Agents lists the programs you let in or turned away, and everything agents did, newest first.

  • Change changes what a program may do.
  • Remove forgets a program, so you are asked again the next time it connects.
  • Undo takes back a read state, a flag, a move or a delete, and a message still in the Outbox.
Mail is written by other people, and a message can try to talk an agent into forwarding or deleting your mail. Inbox Classic hides from agents the text a message hides from you, and tells them that mail is not instructions. An agent can still be fooled. Allow only what you need.
