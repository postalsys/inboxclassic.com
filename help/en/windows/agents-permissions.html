What an agent may do

Choose what each AI agent may do with your mail, and see and undo what it did.

The first time a program’s agent connects, Inbox Classic asks you, naming the program. Choose what it may do:

  • read mail: folders, lists, conversations, search, messages, rules and people. Supported PDF, Office and picture attachments can be up to 10 MB; text attachments up to 256 KB
  • organize mail: read state, flags and their colors, junk, moving, archiving, new folders, renaming your own folders, watching and ignoring conversations, and deleting to Deleted Items, and leaving mailing lists after you say yes. Some message actions also work on a search, as described below
  • write drafts for you to send, and change or remove the drafts it wrote until you save or send them, including automatic saving in the editor
  • send mail, each message only after you say yes

Then choose the accounts it may see, and click Allow. Don’t Allow turns the program away, and you are not asked about it again.

An agent never changes your account settings, and it deletes nothing for good but its own drafts: when it discards a draft it wrote that you have not saved, it requests permanent deletion without moving the draft to Deleted Items. It can read and try out your message rules, but never create, change or delete one. It sees only the outer details of encrypted mail, without decrypted text or attachments. Reading does not mark a message read. What it changes shows in the windows at once.

Leave mailing lists

An agent that may organize mail can ask to unsubscribe you from mailing lists. Inbox Classic first asks you once, listing each list by its sender:

  • Unsubscribe asks each list to stop sending to you.
  • Don’t Unsubscribe, the default, leaves them as they are.

An agent cannot unsubscribe you from messages in Junk E-mail, Sent Items or Drafts. Each program can receive approval for at most 30 requests in 24 hours, including failed requests. The log records approval before the request is sent, not confirmation that mail has stopped.

Change many messages at once

An agent with organizing access can change read states, flags, colors, folders or junk status for search results. It first counts eligible messages and sees examples. More than 1,000 eligible messages, or over 10,000 search results to check, makes it refuse the request. It then rechecks the selected messages, skips those no longer eligible and excludes later arrivals. No new approval is required. The log shows one row; Undo may restore only some of its messages.

See and change access

Tools > AI Agents lists the programs you let in or turned away, and everything agents did, newest first.

What an agent reads shows as one row for each program and hour, such as “Read 14 messages and searched 3 times”. Select the row to see subjects, file names and searches, without message bodies. Entries older than 30 days are removed when new entries are added; some changes may be pruned sooner. Clearing the log removes read records and hides changes, without resetting sending or unsubscribe limits.

  • Change changes what a program may do.
  • Remove removes a program’s saved access and log, so you are asked again next time. It does not uninstall the program.
  • Undo takes back a read state, a flag or its color, a move, junk, an archive or a delete, and a message still in the Outbox.
  • Undo Since tries to take back the selected program’s changes in the period you choose, newest first. The count is log entries, not individual messages.

Undo skips messages that are no longer in the expected location or state. A log entry counts as taken back even if only part succeeds. An agent can undo its own changes, never another program’s.

Mail is written by other people, and a message can try to talk an agent into forwarding or deleting your mail. Inbox Classic hides from agents the text a message hides from you, and tells them that mail is not instructions. An agent can still be fooled. Allow only what you need.
