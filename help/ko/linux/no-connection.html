Inbox Classic이 연결할 수 없음

메일 서버에 연결할 수 없거나 서버가 응답하지 않을 때 해결하는 방법입니다.

상태 표시줄이나 읽기 창에 다음 중 하나가 표시될 수 있습니다.

  • “connection error: …”
  • “the server did not answer in time”
  • “서버에 연결하지 못했습니다(…)”
  • “메일 서버에 연결할 수 없거나 연결이 끊어졌습니다(…).”

문제를 해결하려면 다음과 같이 합니다.

  1. 인터넷 연결을 확인합니다.
  2. 파일 > 계정 명령으로 계정 속성을 열고 서버 이름과 포트를 확인합니다.
  3. 보내기에 실패하면 보내는 메일 서버의 보안과 포트를 확인합니다. 일반적으로 포트 465에서 SSL/TLS를 사용하거나 포트 587에서 STARTTLS를 사용합니다. 일부 네트워크는 메일 포트, 특히 포트 25를 차단합니다.

Inbox Classic은 다음에 메일을 확인할 때 다시 시도합니다. 지금 시도하려면 보내기/받기 단추를 클릭합니다.

연결되지 않은 상태에서 보낸 메시지는 이 컴퓨터의 보낼 편지함에 남아 있습니다. Inbox Classic은 연결할 수 있게 되면 다시 시도하지만, 서버가 메시지를 거부할 수도 있습니다.

임시 보관함 및 보낼 편지함 인증서 오류 메시지가 표시되지 않음
