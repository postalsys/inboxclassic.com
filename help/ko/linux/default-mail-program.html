Inbox Classic을 메일 앱으로 사용

웹 페이지와 다른 프로그램의 전자 메일 링크와 메시지 파일을 Inbox Classic에서 엽니다.

전자 메일 링크(mailto:)를 클릭하면 기본 메일 앱에서 새 메시지가 열립니다.

Inbox Classic을 기본 메일 앱으로 만들려면 도구 > 기본 메일 앱으로 지정을 선택합니다. Inbox Classic이 시스템에 기본 메일 앱으로 설정해 달라고 요청합니다. 실제로 바뀌는지는 시스템 권한과 설정에 따라 다릅니다.

그 후 전자 메일 링크를 클릭하면 링크의 주소, 제목, 본문이 채워진 새 메시지가 열립니다. 링크의 다른 내용은 사용되지 않습니다.

아직 계정이 없으면 Inbox Classic이 먼저 계정을 추가하라고 요청합니다. 계정을 추가한 후 링크를 다시 클릭합니다.

메시지 파일

.eml 파일을 두 번 클릭했을 때 Inbox Classic에서 열리게 하려면 주 메뉴 > 기본 설정 > 일반 페이지에서 Inbox Classic으로 .eml 파일 열기 단추를 클릭합니다. Inbox Classic이 시스템에 이 파일을 Inbox Classic으로 열도록 요청합니다.
