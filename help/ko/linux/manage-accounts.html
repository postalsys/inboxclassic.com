계정 변경, 정렬 및 제거

계정 이름을 바꾸거나, 설정이나 암호를 변경하거나, 계정을 원하는 순서로 정렬하거나, 계정을 제거합니다.

계정 변경

  1. 파일 > 계정을 선택합니다. 창에 계정이 나열됩니다.
  2. 계정을 선택하고 속성 단추를 클릭하거나 계정을 두 번 클릭합니다.
  3. 필요한 내용을 변경하고 확인 단추를 클릭합니다.
  • 계정 이름 필드: 폴더 목록에 표시되는 계정 이름입니다(예: Gmail 또는 회사).
  • 표시 이름 필드: 메시지를 받는 사람에게 보이는 이름입니다.
  • 암호를 그대로 두려면 암호 필드를 비워 둡니다.
  • 브라우저를 통해 로그인하는 계정에는 사용하는 로그인 앱이 표시됩니다.
  • 보낼 때 사용하는 다른 주소 필드: 이 계정으로 보낼 때 사용하는 별칭 같은 다른 주소를 쉼표로 구분하여 나열합니다. Sales <sales@example.com>처럼 쓰거나 주소만 씁니다. 그러면 보낸 사람 필드에서 계정 아래에 이 주소들을 선택할 수 있습니다.
  • 보낸 사람 확인 결과를 신뢰할 서버 필드에는 계정에서 보낸 사람 확인 결과를 신뢰할 서버를 나열합니다. 메일 서버는 각 메시지의 머리글에 확인 결과를 기록합니다. Inbox Classic은 신뢰할 수 있는 결과로 발신 도메인을 확인하고 브랜드 로고, 일회용 코드, 구독 취소 옵션을 표시할지, 신뢰할 수 있는 보낸 사람의 그림을 불러올지 결정합니다. 알려진 공급자는 공급자의 기본값을 사용하고, 그 외에는 받는 메일 서버의 도메인과 전자 메일 주소의 도메인을 사용합니다. 공급자가 mx.example.net 같은 다른 이름으로 확인 결과를 기록한다면 여기에 해당 이름을 입력합니다. 여러 이름은 쉼표로 구분합니다. 필드를 비우면 기본값으로 돌아갑니다. 변경 후 계정이 동기화되면 저장된 메일을 백그라운드에서 다시 확인합니다.

같은 창의 추가 단추를 클릭하면 다른 계정을 추가할 수 있습니다.

계정 순서 정하기

계정이 두 개 이상이면 폴더 목록의 계정이나 모든 받은 편지함 폴더 아래의 계정 행을 다른 계정의 위나 아래로 끌어 놓습니다. 놓일 위치가 선으로 표시됩니다. 또는 계정을 마우스 오른쪽 단추로 클릭하고 위로 이동 또는 아래로 이동을 선택합니다. 폴더 목록과 모든 받은 편지함 폴더 아래의 행 모두 새 순서를 따릅니다.

계정 메뉴

계정이 두 개 이상이면 폴더 목록에서 계정 이름을 마우스 오른쪽 단추로 클릭하여 메뉴를 엽니다. 계정이 하나뿐이면 계정 이름 행이 없습니다. 이때는 파일 > 계정 명령으로 속성을 열고, 다른 계정 명령은 도구 메뉴에서 찾습니다.

  • 보내기/받기: 그 계정만 확인합니다.
  • 모두 읽은 상태로 표시: 계정의 모든 폴더를 읽은 것으로 표시합니다.
  • 새 폴더, 속성, 위로 이동, 아래로 이동 명령도 있습니다.

계정 제거

계정을 제거하면 이 컴퓨터에서 그 계정용으로 다운로드한 메일과 저장된 로그인 자격 증명이 삭제됩니다. 서버에 사본이 없는 메시지를 포함하여 그 계정의 로컬 보낼 편지함에 있는 보내지 않은 메시지도 삭제됩니다. 서버에 있는 메일은 그대로 남습니다.

계정을 제거하려면 다음과 같이 합니다.

  1. 파일 > 계정을 선택합니다.
  2. 계정을 선택하고 제거 단추를 클릭하거나, Windows에서는 Del 키를 누릅니다.
  3. 확인합니다. 계정이 폴더 목록에서 제거됩니다.
