첨부 파일

메시지에 첨부된 파일을 열거나 저장하고, 작성하는 메시지에 파일을 첨부합니다.

메시지에서 그림 및 PDF 파일 보기

그림 미리 보기와 각 PDF 파일의 처음 다섯 페이지까지가 메시지 본문 뒤에 이름 및 크기와 함께 표시됩니다. 미리 보기를 클릭하면 파일이 열립니다. 더 긴 PDF 파일에는 파일을 여는 링크가 있습니다. 그림과 페이지는 20개까지 자동으로 표시되며, 그 아래 줄에 나머지 파일의 수가 표시됩니다.

이 미리 보기는 Inbox Classic이 직접 그린 사본입니다. 파일 안의 어떤 내용도 실행되지 않으며 인터넷에서 아무것도 불러오지 않습니다. 그릴 수 없는 파일(예: HEIC 그림이나 암호로 보호된 PDF 파일)은 이름, 크기, 이유가 적힌 타일로 표시되며, 타일을 클릭하면 파일이 열립니다. 큰 메시지를 아직 다운로드하는 동안에는 파일이 도착할 때까지 타일로 표시됩니다. 서명되었거나 암호화된 메시지에서는 각 부분의 파일이 그 부분의 틀 안에 따로 표시됩니다. 암호화된 부분의 미리 보기는 미리 보기 파일이 아닌 메모리에만 보관됩니다. 첨부 파일을 따로 열거나 저장하면 암호화되지 않은 사본이 기록됩니다.

파일을 메시지 안에 표시하거나 메시지에서 빼려면 파일 목록에서 파일을 마우스 오른쪽 단추로 클릭하고 메시지에 표시 명령을 선택합니다. 이 설정은 메시지가 표시되어 있는 동안 유지됩니다.

목록만 보려면 도구 > 옵션 > 읽기 페이지에서 메시지에 첨부 파일 표시 확인란을 선택 취소합니다. 파일 미리 보기를 그리는 동안 Inbox Classic이 중단되면, 다음에 시작할 때 PDF 미리 보기를 끄고 그 사실을 알려 줍니다. 그렇다고 해서 그 파일 때문에 중단되었다는 뜻은 아닙니다. PDF 미리 보기를 다시 표시하려면 메시지에 PDF 파일 표시 확인란을 선택합니다.

메시지를 인쇄하면 메시지에 표시된 그림 미리 보기도 함께 인쇄됩니다. PDF 파일은 인쇄되지 않으며, 대신 각 파일의 이름이 한 줄씩 인쇄됩니다. PDF 파일은 해당 프로그램에서 인쇄합니다. 서명되었거나 암호화된 메시지에서는 각 부분의 그림이 그 부분의 텍스트 바로 뒤에 부분 이름과 함께 인쇄됩니다.

첨부 파일 열기

메시지의 파일은 메시지 머리글 아래에 이름 및 크기와 함께 나열됩니다. 파일을 두 번 클릭하면 컴퓨터에서 그 파일에 사용하는 프로그램으로 열립니다. 키보드를 사용할 때는 파일이 선택될 때까지 Tab 키를 누르고, 화살표 키로 파일을 고른 다음 Enter 키를 누릅니다.

파일을 마우스 오른쪽 단추로 클릭하면 열기, 다른 이름으로 저장, 모두 저장 명령을 사용할 수 있습니다. 머리글 오른쪽의 클립 아이콘에서도 파일 목록을 볼 수 있습니다.

Inbox Classic은 인식된 프로그램, 스크립트, 설치 프로그램, 바로 가기, 디스크 이미지, 웹 페이지, 매크로가 포함된 Office 문서는 열지 못하도록 차단합니다. 이러한 파일에서는 열기 명령을 사용할 수 없습니다. 파일을 저장한 다음, 보낸 곳을 신뢰할 수 있는 경우에만 직접 여십시오.

파일을 열 때 Inbox Classic은 사용자 계정의 임시 폴더에 사본을 저장합니다. 앱은 시작할 때 하루가 지난 임시 사본을 지우려고 시도합니다. Windows와 macOS에서는 파일이 인터넷에서 온 것으로 표시됩니다. 암호화된 메시지의 첨부 파일은 이곳에 암호화되지 않은 상태로 저장되며, Inbox Classic은 이러한 파일을 처음 열 때 이 사실을 알려 줍니다.

첨부 파일 저장

파일을 마우스 오른쪽 단추로 클릭하고 다른 이름으로 저장을 선택하거나, 모든 파일을 한 폴더에 저장하려면 모두 저장을 선택합니다. Inbox Classic은 이름을 다른 것처럼 보이게 할 수 있는 문자를 뺀 안전한 이름을 제안합니다. 모든 첨부 파일을 저장할 때 기존 파일은 그대로 두고, 이름이 같은 새 파일에는 번호를 붙입니다. 파일 하나를 저장할 때는 시스템의 저장 대화 상자를 따르며, 이 대화 상자에서 파일을 바꿀지 물을 수 있습니다.

받을 것으로 예상한 사람이 보낸 첨부 파일만 여십시오. 프로그램이나 “콘텐츠 사용”을 요구하는 문서는 컴퓨터를 장악할 수 있습니다. 프로그램에는 .exe, .msi, .js, .vbs, .bat, .scr 파일이 있습니다.

파일 첨부

작성하는 메시지에 파일을 첨부하려면 다음과 같이 합니다.

  1. 첨부 단추를 클릭합니다.
  2. 파일을 선택합니다. 선택한 파일이 크기와 함께 첨부 파일 필드에 나열됩니다.

파일 탐색기에서 주소 필드로 파일을 끌어 놓아도 됩니다. 그림이 아닌 파일은 본문에 끌어 놓아도 첨부됩니다.

파일을 빼려면 파일을 선택하고 Del 키를 누르거나, 마우스 오른쪽 단추로 클릭하고 제거를 선택합니다. 파일은 메시지를 보낼 때 읽히므로 그때까지 파일을 원래 위치에 두십시오.
