설정

Inbox Classic의 언어, 메일을 표시하고 알리는 방법, 미리 다운로드할 항목을 선택합니다.

도구 > 옵션 창을 엽니다. 설정은 일반, 읽기, 다운로드의 세 페이지로 나뉘어 있습니다. 변경 내용을 유지하려면 확인 단추를 클릭하고, 유지하면서 창을 열어 두려면 적용 단추를 클릭합니다. 취소 단추는 대화 상자를 연 후나 마지막으로 적용한 후의 변경 내용을 취소하며, 적용하지 않은 신뢰할 수 있는 보낸 사람 제거도 취소합니다. Windows 설정에서 .eml 파일용으로 선택한 앱은 그대로 유지됩니다.

일반

  • 언어 설정에서 창과 이 도움말의 언어를 시스템 언어나 목록의 언어 중에서 선택합니다. Inbox Classic은 시스템의 기본 언어를 차례로 시도하며, 지원되는 언어가 없으면 영어를 사용합니다.
  • 새 메일이 도착하면 알림 확인란을 선택하면 기본 창이 앞에 있지 않고 시스템이 허용할 때 새 메일 알림이 표시됩니다. 처음에는 켜져 있습니다.
  • 새 메일 알림에 로그인 코드 표시 확인란을 선택하면 로그인 메시지의 코드가 알림에 표시됩니다. 알림은 잠긴 화면에서도 읽을 수 있으므로 처음에는 꺼져 있으며, 알림이 꺼져 있는 동안에는 사용할 수 없습니다.
  • 보내기 전 지연 시간 설정은 보내기 시작을 늦추어, 카운트다운이 끝나기 전에 실행 취소로 보내기를 취소할 수 있게 합니다. 처음에는 10초입니다.
  • 기본 메일 앱으로 지정 단추로 전자 메일 링크에 Inbox Classic을 사용하도록 선택할 수 있으며, Inbox Classic으로 .eml 파일 열기 단추로 메시지 파일에 사용하도록 선택할 수 있습니다. Inbox Classic을 메일 앱으로 사용 항목을 참조하십시오.

언어를 바꾸려면 Inbox Classic을 다시 시작해야 합니다. 지금 다시 시작 단추를 클릭하거나, 다음에 시작할 때 바꾸려면 나중에 단추를 클릭합니다.

읽기

  • 레이아웃 설정에서 창 너비에 따른 자동, 클래식, 열 중에서 레이아웃을 선택합니다. 레이아웃 항목을 참조하십시오.
  • 대화별로 메시지 그룹화 확인란을 선택하면 서로 회신하는 메시지가 한 행으로 묶입니다. 처음에는 켜져 있습니다.
  • 메시지 목록에 보낸 사람 그림 표시 확인란을 선택하면 열 레이아웃에 브랜드 로고, 연락처 사진, 이니셜이 표시됩니다. 처음에는 켜져 있습니다.
  • 메시지에 첨부 파일 표시 확인란을 선택하면 메시지 본문 뒤에 그림과 PDF 파일의 처음 몇 페이지가 표시됩니다. 처음에는 켜져 있습니다. 그림은 표시하되 PDF 파일은 표시하지 않으려면 메시지에 PDF 파일 표시 확인란을 선택 취소합니다. 첨부 파일 항목을 참조하십시오.
  • 모든 메시지의 그림 다운로드 확인란을 선택하면 정크 메일과 암호화된 메시지 부분을 제외하고 원격 그림을 자동으로 불러옵니다. 그러면 보낸 사람이 메시지를 읽은 시점을 알 수 있으므로 처음에는 꺼져 있습니다. 그림과 추적 항목을 참조하십시오.
  • 신뢰할 수 있는 보낸 사람 단추를 클릭하면 신뢰할 수 있는 보낸 사람 주소와 도메인의 목록이 표시되며, 여기서 제거할 수 있습니다. 자동으로 불러오려면 도메인이 확인되어야 하며, 정크 메일과 암호화된 부분은 여전히 제외됩니다.
  • 암호화된 메시지에서 검색 확인란을 선택하면 사용할 수 있는 암호 해독 키가 있을 때 다운로드한 암호화된 메시지를 색인하여, 본문과 보호된 제목을 검색할 수 있게 합니다. 처음에는 켜져 있습니다. 본문과 보호된 제목은 로컬 색인에 암호화되지 않은 상태로 보관됩니다. 이 옵션을 끄면 암호 해독된 색인 데이터가 제거되고 바깥쪽 제목이 다시 표시됩니다. 에이전트의 텍스트 검색에는 이 암호 해독된 색인이 포함되지 않습니다.
  • keys.openpgp.org에서 키 찾기 확인란을 선택하면 Inbox Classic이 암호화하여 보낼 주소의 키를 주소의 도메인에 먼저 물은 후 keys.openpgp.org에 묻습니다. 요청에 따라 주소, 지문 또는 키 ID가 전송될 수 있습니다. 조회는 암호화하거나 키를 찾을 때 일어납니다. 처음에는 켜져 있습니다.

다운로드

  • 미리 메시지 다운로드 설정에서 메시지를 열기 전에 다운로드할 메시지를 선택합니다. 처음에는 각각 1MB 이하의 최근 메시지입니다. 미리 다운로드한 메시지 항목을 참조하십시오.
  • 계정당 저장 공간 한도 설정은 계정별로 캐시되는 메시지 내용의 양을 정합니다. 초안과 이번 실행 중에 연 메시지는 포함되지 않습니다. 데이터베이스 크기의 엄격한 한도는 아닙니다. 처음에는 1GB입니다.

설치 프로그램은 처음 설치할 때 언어를 묻고, 그 언어를 여기서 선택한 언어로 유지합니다.
