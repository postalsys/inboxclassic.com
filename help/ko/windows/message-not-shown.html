메시지가 표시되지 않음

메시지를 아직 다운로드하는 중이거나, 다운로드할 수 없거나, 표시할 수 없을 때 해결하는 방법입니다.

“메시지를 다운로드하는 중…”

메시지는 처음 열 때 다운로드됩니다. 계정을 추가한 직후에는 대부분의 메시지가 아직 컴퓨터에 없습니다. 내용의 다운로드가 끝나기 전에 보낸 사람과 제목이 먼저 표시될 수 있습니다. 다운로드 시간은 연결 상태와 메시지 크기에 따라 다릅니다.

“메시지를 다운로드할 수 없습니다”

읽기 창에 이유가 표시됩니다(예: 메일 서버에 연결할 수 없음). 다운로드에 실패한 메시지가 열려 있으면 계정이 동기화된 후 다시 시도합니다. 바로 시도하려면 메시지 위의 막대에서 다시 시도 단추를 클릭합니다.

로그인이 거부된 경우 암호가 받아들여지지 않음 항목을 참조하십시오. 보안 연결을 설정할 수 없는 경우 인증서 오류 항목을 참조하십시오.

“이 메시지를 표시할 수 없습니다: …”

메시지가 손상되었거나 지원되지 않는 구조를 사용하는 등의 이유로 Inbox Classic이 메시지를 읽을 수 없었습니다. 다른 메일 프로그램에서는 읽을 수 있을 수도 있습니다. 나머지 메일에는 영향이 없습니다. 메시지의 내용을 보려면 보기 > 메시지 원본을 선택합니다.

“WebView2 런타임을 사용할 수 없습니다”

Inbox Classic은 메시지를 표시하는 데 Microsoft Edge WebView2 런타임을 사용합니다. 런타임이 없으면 Microsoft에서 설치한 다음 Inbox Classic을 다시 시작합니다. Edge 브라우저가 설치되어 있다고 해서 런타임을 사용할 수 있는 것은 아닙니다.

Inbox Classic이 연결할 수 없음 메시지 읽기 메시지 저장, 인쇄 및 가져오기
