계정 보안 설정

계정 서버의 보안 설정과 각 설정의 의미입니다.

각 계정에는 받는 메일 서버의 IMAP 보안 설정과 보내는 메일 서버의 SMTP 보안 설정이 있습니다. Inbox Classic은 공급자의 설정을 찾으면 이 값을 채웁니다. 바꾸려면 파일 > 계정 명령에서 계정 속성을 엽니다.

설정의미
SSL/TLS처음부터 연결이 암호화됩니다. 일반적으로 받는 메일은 포트 993, 보내는 메일은 포트 465를 사용합니다.
STARTTLS암호화되지 않은 상태로 연결을 시작한 다음, 로그인 정보를 보내기 전에 TLS로 전환합니다. 일반적으로 받는 메일은 포트 143, 보내는 메일은 포트 587을 사용합니다. 서버가 암호화를 제공하지 않으면 Inbox Classic은 연결을 중지합니다.
없음(암호화 안 함)암호와 메일이 암호화되지 않은 채 전송되므로 연결을 가로채는 사람이 읽을 수 있습니다.
없음(암호화 안 함) 설정은 연결이 다른 방법으로 보호되는 경우에만 사용하십시오. 로컬 네트워크라고 해서 암호화되는 것은 아닙니다. Inbox Classic은 이 설정을 사용하기 전에 경고합니다.

암호화된 연결에서는 Inbox Classic이 시스템이 신뢰하는 인증서를 기준으로 서버의 신원을 확인합니다. 모든 인증서를 허용하는 옵션은 없습니다.

기본적으로 암호는 메일 저장소가 아니라 Windows 자격 증명 관리자에 보관됩니다. 브라우저 로그인을 사용하면 암호 대신 토큰이 그곳에 저장됩니다. 메모리 전용 모드를 사용하거나 시스템 저장소를 사용할 수 없으면 로그인 정보가 현재 세션 동안만 유지될 수 있습니다.
