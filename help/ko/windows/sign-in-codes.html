로그인 코드

로그인 코드나 확인 코드가 들어 있는 메시지에는 코드를 복사할 수 있는 카드가 표시됩니다.

Inbox Classic이 조건에 맞는 로그인, 확인 또는 승인 코드를 인식하면 메시지 위의 카드에 다음이 표시됩니다.

  • 코드가 사용되는 도메인을 알려 주는 “…의 코드”
  • 큰 글자로 표시된 코드
  • 코드를 클립보드에 복사하는 복사 단추
카드에 표시된 도메인의 페이지에서만 코드를 입력하십시오. 다른 곳에 코드를 입력하라고 요구하는 메시지는 계정을 가로채려는 시도일 수 있습니다.

카드는 해당 도메인이나 그 상위 도메인의 서명을 메일 공급자가 확인한 경우에만 표시됩니다. 이것으로 개별 보낸 사람이나 메시지의 모든 내용이 확인되는 것은 아닙니다. 정크 메일, 보낸 편지함, 임시 보관함 폴더의 메시지와 공급자가 서명 결과를 알려 주지 않는 경우에는 카드가 표시되지 않습니다.

메시지 날짜가 1시간보다 오래되었으면 카드에 코드가 만료되었을 수 있다는 경고가 표시됩니다. Inbox Classic은 서비스에 만료 여부를 확인하지 않습니다.

알림에 표시되는 코드

새 메시지 알림에 코드를 표시하려면 도구 > 옵션 > 일반 페이지에서 새 메일 알림에 로그인 코드 표시 확인란을 선택합니다. 알림은 잠긴 화면에서도 보일 수 있으므로 이 옵션은 기본적으로 꺼져 있습니다. 코드는 알림이 허용되어 있고 새 메시지를 제때 다운로드하여 확인할 수 있을 때에만 표시됩니다.

새 메일 받기 링크, 스크립트 및 첨부 파일 메일과 암호가 저장되는 위치
