폴더 작업

메일 서버에 직접 사용할 폴더를 만들고, 이름을 바꾸고, 삭제합니다.

폴더를 만들려면 다음과 같이 합니다.

  1. 하위 폴더를 만들려면 상위 폴더를 선택합니다. 계정이 하나일 때 최상위 폴더를 만들려면 받은 편지함이나 플래그 지정됨 폴더를 선택합니다. 계정이 여러 개이면 대신 계정 이름을 마우스 오른쪽 단추로 클릭합니다.
  2. 파일 > 새 폴더를 선택하거나, 마우스 오른쪽 단추로 클릭하고 새 폴더를 선택합니다.
  3. 이름을 입력하고 확인 단추를 클릭합니다. Inbox Classic이 서버에 폴더를 만들고, 실패하면 알려 줍니다.

선택한 폴더의 이름을 바꾸려면 파일 > 폴더 이름 바꾸기를 선택합니다. 삭제하려면 파일 > 폴더 삭제를 선택합니다. 두 명령 모두 폴더를 마우스 오른쪽 단추로 클릭했을 때 나타나는 메뉴에도 있습니다.

폴더를 삭제하면 그 안의 메시지와 폴더도 서버에서 함께 삭제됩니다. Inbox Classic은 삭제하기 전에 확인을 요청합니다.

받은 편지함과 보낸 편지함, 임시 보관함, 지운 편지함 같은 특수 폴더는 이름을 바꾸거나 삭제할 수 없습니다.

마우스를 사용하지 않고 폴더를 열려면 보기 > 폴더로 가기(⇧⌘Y)를 선택하고 폴더 이름의 일부를 입력합니다.

폴더 목록은 어떤 폴더를 펼치고 접었는지 기억합니다.
