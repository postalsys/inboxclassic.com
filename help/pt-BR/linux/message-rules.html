Organizar os e-mails novos com regras

Mova, marque como lidas, sinalize ou arquive automaticamente as mensagens recebidas que atendem aos seus critérios.

Uma regra combina critérios de pesquisa com ações a aplicar às mensagens correspondentes quando elas chegam à Caixa de Entrada das contas escolhidas na regra. Por exemplo, uma regra com from:news@example.com pode mover os boletins desse endereço para uma pasta separada e marcá-los como lidos.

Para criar uma regra:

  1. Escolha Ferramentas > Regras de mensagens e clique em Nova.
  2. Digite um nome e preencha Critérios de pesquisa com os mesmos termos da caixa de pesquisa, como from:, subject: ou list:. A linha abaixo mostra quantas mensagens já presentes na Caixa de Entrada correspondem a esses critérios.
  3. Escolha uma ou mais ações para as mensagens correspondentes: movê-las para uma pasta, marcá-las como lidas, sinalizá-las, arquivá-las, movê-las para Lixo Eletrônico, excluí-las ou não mostrar notificações.
  4. Clique em OK.

Você também pode criar uma regra a partir de uma mensagem ou de uma pesquisa. Escolha Mensagem > Criar regra a partir da mensagem para preencher a lista de e-mails da mensagem selecionada, se houver List-Id, ou o remetente. Clique em Criar regra acima dos resultados da pesquisa para usar os critérios da pesquisa atual.

Como as regras funcionam

As regras processam as mensagens novas da Caixa de Entrada enquanto o Inbox Classic está em execução, inclusive quando a janela está fechada e o aplicativo continua em segundo plano. As mensagens que já existem só são afetadas se você marcar Aplicá-la também às mensagens que já estão na Caixa de Entrada. As regras correspondentes são executadas na ordem da lista. Quando uma regra programa a saída da mensagem da Caixa de Entrada, as regras seguintes deixam de se aplicar, mesmo antes da confirmação da movimentação pelo servidor. Desmarque a caixa de seleção de uma regra na lista para desativá-la sem excluí-la.

Alterar regras

Para editar uma regra, selecione-a na lista e clique em Editar, ou clique duas vezes nela. Use Mover para cima e Mover para baixo para mudar a ordem, ou Excluir para excluir a regra. No editor de regras, clique em Mostrar para fechar o editor sem salvar as alterações e pesquisar os critérios atuais em todas as Caixas de Entrada. Essa pesquisa não se restringe às contas escolhidas na regra, ao contrário da contagem prévia no editor.

As regras se aplicam às mensagens novas da Caixa de Entrada, por isso os filtros de pasta e de data não são suportados. Se você usar in:, before:, after:, older_than: ou newer_than:, uma mensagem explica por que não é possível usar esses filtros. As regras não podem enviar mensagens nem excluí-las permanentemente: Excluir as move para Itens Excluídos, se essa pasta existir.

Se a conta não tiver uma pasta para mensagens excluídas, a ação de excluir de uma regra não apaga as mensagens permanentemente. As regras são executadas neste computador. Para organizar os e-mails enquanto ele está desligado, use os filtros do seu provedor de e-mail.
