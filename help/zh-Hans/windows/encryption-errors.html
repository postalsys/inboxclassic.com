加密错误

服务器不提供加密，或在已关闭加密的情况下要求加密时该怎么办。

“the server does not offer STARTTLS”

该帐户设置为使用 STARTTLS，但服务器没有提供加密。Inbox Classic 在发送密码之前就停止了这次连接尝试。

  1. 在文件 > 帐户中打开帐户属性。
  2. 查看提供商的设置。如果支持，接收邮件请使用 SSL/TLS 和端口 993，发送邮件请使用端口 465。
  3. 单击确定。

如果其他方法都不起作用，说明无法安全地使用该服务器。

“the server takes the password only over an encrypted connection”

发送邮件服务器设置为无（不加密）。此错误并不表示密码正确。请按照提供商的设置，将SMTP 安全性更改为 STARTTLS 和端口 587，或 SSL/TLS 和端口 465。

关于不加密连接的警告

当您选择无（不加密）时，Inbox Classic 会警告：任何截获您网络流量的人都能读取您的密码和邮件。局域网本身并不会加密流量。仅当连接已通过其他方式受到保护时才继续。
