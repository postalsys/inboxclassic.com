Gmail dan Outlook.com

Gunakan proses masuk melalui browser untuk Gmail, Outlook.com, dan Microsoft 365; akun Google yang memenuhi syarat juga dapat menggunakan kata sandi aplikasi.

Google dan Microsoft tidak mengizinkan program email menggunakan kata sandi biasa Anda. Di Inbox Classic, gunakan proses masuk melalui browser untuk Outlook.com dan Microsoft 365. Kata sandi aplikasi Google hanya dapat digunakan jika akun Anda mengizinkannya.

Masuk melalui browser

Klik Masuk dengan Google atau Masuk dengan Microsoft di Tambahkan Akun Email. Anda mengetik kata sandi di halaman milik Google atau Microsoft sendiri, sehingga Inbox Classic tidak pernah melihatnya. Akun seperti ini selalu menggunakan server email milik penyedia sendiri.

Organisasi Microsoft 365 mungkin harus mengizinkan Inbox Classic terlebih dahulu. Microsoft kemudian menampilkan Perlu persetujuan admin, dan Inbox Classic memberi tahu Anda alamat tempat administrator Anda menyetujuinya.

Masuk dengan Google awalnya nonaktif. Dalam konfigurasi ini, aplikasi masuk Google bawaan hanya untuk pengguna uji. Gunakan aplikasi masuk Anda sendiri atau, jika akun Anda mengizinkannya, kata sandi aplikasi (lihat Aplikasi masuk).

Menggunakan kata sandi aplikasi

Kata sandi aplikasi Google memerlukan Verifikasi 2 Langkah dan tidak tersedia untuk setiap akun. Misalnya, kebijakan kantor atau sekolah dan Perlindungan Lanjutan dapat mencegah penggunaannya.

  1. Buka Kata sandi aplikasi di setelan keamanan akun Google Anda dan buat sandi jika opsi tersebut tersedia.
  2. Di Tambahkan Akun Email, ketik nama dan alamat Anda, lalu klik Berikutnya >.
  3. Klik Gunakan Kata Sandi Aplikasi.
  4. Ketik kata sandi aplikasi di Kata sandi, lalu klik Selesai.

Saat sesi masuk berakhir

Jika Google atau Microsoft mengakhiri sesi masuk, Inbox Classic menampilkan “Proses masuk ke … ditolak atau sesinya telah berakhir.” Inbox Classic menanyakan apakah Anda ingin masuk lagi di browser. Pilih Ya dan masuk sekali lagi.
