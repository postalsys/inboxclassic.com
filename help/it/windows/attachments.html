Allegati

Apri o salva gli allegati ricevuti e aggiungi file ai messaggi che scrivi.

Vedere immagini e file PDF nel messaggio

Le immagini e le prime pagine dei file PDF sono mostrate dopo il testo del messaggio, con nome e dimensione. Fai clic su un’anteprima per aprire il file. Un file PDF più lungo ha un link che lo apre. Vengono mostrate automaticamente fino a 20 immagini e pagine PDF in totale, al massimo le prime cinque pagine di ogni PDF. Puoi scegliere di mostrare altri file. Una riga sotto le anteprime indica quanti file restano nell’elenco.

Inbox Classic crea le anteprime senza eseguire script o altri contenuti attivi dei file e senza scaricare contenuti da Internet. Un file di cui non riesce a creare l’anteprima appare come un riquadro con nome, dimensione e motivo, per esempio un’immagine HEIC o un file PDF protetto da password; fai clic sul riquadro per aprire il file. Mentre un messaggio grande è ancora in download, i suoi file appaiono come riquadri finché non arrivano. In un messaggio firmato o crittografato, gli allegati di ogni parte compaiono nel riquadro corrispondente. I dati decrittografati usati per l’anteprima restano in memoria fino al cambio di messaggio. Aprire o salvare il file crea invece una copia in chiaro sul disco. Un’anteprima può essere troppo grande anche perché è stato raggiunto il limite complessivo delle anteprime.

Per mostrare un file nel messaggio, o per toglierlo, fai clic con il pulsante destro sul file nell’elenco e scegli Mostra nel messaggio. Vale finché il messaggio è mostrato.

Per vedere solo l’elenco, disattiva Mostra gli allegati nei messaggi in Strumenti > Opzioni > Lettura. Se Inbox Classic si interrompe durante l’anteprima di un file, le anteprime PDF vengono disattivate e compare un avviso. Non significa necessariamente che un PDF abbia causato il problema; attiva Mostra i file PDF nei messaggi per mostrarli di nuovo.

Le anteprime delle immagini mostrate nel messaggio vengono stampate insieme al testo. I PDF vengono elencati, ma per stamparli devi aprirli nella loro app. Nei messaggi firmati o crittografati, le immagini seguono il testo della parte a cui appartengono, con la relativa etichetta.

Aprire un allegato

Gli allegati di un messaggio sono elencati sotto la sua intestazione, ognuno con nome e dimensione. Fai doppio clic su un file per aprirlo con il programma che il computer usa per quel tipo di file. Con la tastiera, premi Tab fino a raggiungere l’elenco degli allegati, scegline uno con i tasti freccia e premi Invio.

Fai clic con il pulsante destro su un file per accedere ai comandi Apri, Salva con nome e Salva tutti. Anche la graffetta a destra dell’intestazione elenca i file.

Inbox Classic blocca l’apertura diretta dei tipi di file riconosciuti come eseguibili, tra cui programmi, script, programmi di installazione, collegamenti, immagini disco, pagine web e documenti di Office con macro. Per questi file Apri è disattivato; salva il file e aprilo tu stesso solo se ti fidi della sua provenienza.

Per aprire un allegato, Inbox Classic ne salva una copia in una cartella temporanea riservata al tuo account utente. All’avvio, l’app tenta di rimuovere le copie più vecchie di 24 ore. Su Windows e macOS i file vengono contrassegnati come provenienti da internet. Gli allegati dei messaggi crittografati vengono salvati in questa cartella senza crittografia e possono restarci dopo la chiusura del file. Inbox Classic ti avvisa la prima volta che ne apri uno.

Salvare un allegato

Fai clic destro su un file e scegli Salva con nome, oppure scegli Salva tutti per salvarli tutti in una cartella. Inbox Classic propone un nome sicuro, privo di caratteri che potrebbero camuffare il nome del file. Quando salvi più file insieme, quelli già presenti vengono conservati e ai nuovi nomi viene aggiunto un numero. Quando salvi un solo file, l’eventuale sostituzione è gestita dalla finestra di salvataggio del sistema.

Apri solo gli allegati che ti aspetti di ricevere dal mittente. Un programma, o un documento che ti chiede di “abilitare il contenuto”, può prendere il controllo del computer. Tra i programmi ci sono i file .exe, .msi, .js, .vbs, .bat e .scr.

Allegare un file

Per allegare file al messaggio che scrivi:

  1. Fai clic su Allega.
  2. Scegli i file. Vengono elencati in Allegati con le loro dimensioni.

Puoi anche trascinare i file da Esplora file sui campi degli indirizzi. Un file che non è un’immagine si può trascinare anche sul testo.

Per togliere un file, selezionalo e premi Canc, oppure fai clic destro su di esso e scegli Rimuovi. I file vengono letti quando il messaggio viene inviato, quindi lasciali dove sono fino ad allora.
