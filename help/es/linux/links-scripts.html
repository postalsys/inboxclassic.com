Enlaces, scripts y archivos adjuntos

Cómo impide Inbox Classic que un mensaje ejecute código o abra páginas por su cuenta.

  • Los scripts de los mensajes nunca se ejecutan. Inbox Classic elimina el contenido ejecutable antes de mostrar el mensaje. No ejecuta código procedente del mensaje.
  • Los enlaces a páginas web se abren en el navegador. Los enlaces de correo pueden abrir un mensaje nuevo en Inbox Classic. Un mensaje no puede abrir una página ni una ventana por sí solo.
  • Los archivos adjuntos pueden guardarse o abrirse, a petición suya, con una aplicación externa. Inbox Classic elimina de sus nombres caracteres peligrosos o engañosos antes de guardarlos.
  • La cancelación de suscripciones le pregunta antes e indica lo que va a hacer.
Antes de escribir una contraseña en una página a la que llegó desde un mensaje, compruebe la dirección en el navegador. Un mensaje puede mostrar una dirección y enlazar a otra.

Cuando escribe un mensaje, la barra de estado muestra adónde lleva el enlace en el que está el cursor, para que pueda comprobarlo antes de enviar.

Un código de inicio de sesión solo se ofrece cuando su proveedor de correo confirma una firma del dominio asociado al código o de un dominio superior. Esto no identifica a la persona que escribió el mensaje. Consulte Códigos de inicio de sesión.

Inbox Classic procesa las imágenes incluidas en el mensaje y genera copias para mostrarlas. Esas copias se muestran en el visor del sistema. No utiliza las fuentes incluidas en el mensaje.
