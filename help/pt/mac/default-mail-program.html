Definir o Inbox Classic como aplicação de correio predefinida

Abra no Inbox Classic as ligações de e-mail e os ficheiros de mensagens de páginas web e de outros programas.

As ligações de e-mail (mailto:) abrem uma nova mensagem na sua aplicação de correio predefinida.

Para definir o Inbox Classic como aplicação de correio predefinida, escolha Ferramentas > Definir como aplicação de correio predefinida. O Inbox Classic pede ao sistema para o definir como aplicação de correio predefinida; o resultado depende das definições do sistema.

A partir daí, ao clicar numa ligação de e-mail, abre-se uma nova mensagem com os endereços, o assunto e o texto da ligação já preenchidos. Os restantes dados da ligação são ignorados.

Se ainda não tiver nenhuma conta, o Inbox Classic pede-lhe que adicione uma primeiro. Depois de a adicionar, clique novamente na ligação.

Ficheiros de mensagens

Para abrir os ficheiros .eml no Inbox Classic quando faz duplo clique neles, clique em Abrir ficheiros .eml com o Inbox Classic em Inbox Classic > Definições > Geral. O Inbox Classic pede ao sistema para o associar a esses ficheiros; a associação depende das definições do sistema.
