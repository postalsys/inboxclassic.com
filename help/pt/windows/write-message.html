Escrever uma mensagem

Escreva e envie uma nova mensagem, com formatação, ligações e imagens.

Para escrever uma mensagem:

  1. Clique em Nova mensagem, ou prima Ctrl+N. Abre-se uma nova mensagem numa janela própria.
  2. Escreva os endereços em Para. Separe os endereços com vírgulas. À medida que escreve, o Inbox Classic sugere endereços e grupos correspondentes. Prima Enter ou Tab para escolher uma sugestão.
  3. Escreva o Assunto e o texto.
  4. Clique em Enviar, ou prima Ctrl+Enter.

Para adicionar Cc ou Bcc, clique em Cc ou Bcc no fim da linha Para. As pessoas em Bcc recebem a mensagem, mas os outros destinatários não as veem.

O campo De mostra a conta a partir da qual a mensagem é enviada. Com várias contas, pode escolher outra nesse campo. A mensagem é então enviada com essa conta e guardada nos respetivos Itens Enviados. Para começar a partir de uma determinada conta, use a seta ao lado de Nova mensagem.

Se o assunto ou o texto contiver uma palavra reconhecida como referência a um anexo, como a palavra inglesa «attached», mas não houver nenhum ficheiro anexado, o Inbox Classic pede confirmação antes de enviar a mensagem. O aviso só reconhece determinadas palavras em inglês, alemão, estónio, espanhol e francês. Não procura no texto da assinatura nem nas mensagens citadas.

Para assinar digitalmente ou encriptar a mensagem, clique em Assinar ou Encriptar na barra de ferramentas. Consulte Assinar e encriptar uma mensagem.

Formatação

A barra por cima do texto tem o tipo de letra, negrito, itálico, sublinhado, cor, listas, avanço, alinhamento, ligações, uma linha divisória e imagens. Para colocar uma imagem no texto, clique em Inserir imagem ou arraste um ficheiro de imagem do Explorador de Ficheiros para o texto.

Uma mensagem sem formatação é enviada como texto simples, que todos os programas de correio conseguem apresentar. Uma mensagem formatada é enviada como HTML com uma cópia em texto simples.

Ligações

Para criar uma ligação no texto selecionado, clique em Hiperligação e escreva o endereço. A barra de estado mostra a ligação sob o ponteiro ou, na ausência dela, junto ao cursor de texto. Ctrl+Click numa ligação web abre-a no browser. Clique nela com o botão direito do rato para aceder a Abrir ligação, Editar ligação e Remover ligação.

As palavras com erros ortográficos ficam sublinhadas. Clique numa com o botão direito do rato para ver sugestões.
