Tehisintellekti agendi ühendamine

Laske tehisintellekti agendil, näiteks Claude'il, Inbox Classicu kaudu teie posti lugeda ja korraldada.

Saate lasta tehisintellekti agendil oma postiga töötada. See võib olla Claude, Cursor või mõni muu programm, mis toetab Model Context Protocoli (MCP). Inbox Classicus endas pole tehisintellekti ja tehisintellekti teenusele ei saadeta midagi, kui te agenti sisse ei lase.

Agendi ühendamiseks tehke järgmist.

  1. Valige Tööriistad > Tehisintellekti agendid ja klõpsake nuppu Kuidas agenti ühendada. Inbox Classic näitab ridu, mis tuleb lisada agendi sätetesse.
  2. Lisage need oma agendi MCP-serverite hulka. Claude Desktopis on see Settings > Developer > Edit Config.
  3. Käivitage agent. Esimesel ühendumisel küsib Inbox Classic teilt, mida see teha tohib.

Kui Inbox Classic ei tööta, käivitab agent selle taustal. Sellele pääsevad ligi ainult programmid, mis töötavad selles arvutis teie nime all.

Inbox Classic küsib süsteemilt, milline programm agendi käivitas. Agent ei saa teise programmi õigusi lihtsalt selle nime esitades. Kui esitatud nimi erineb tuvastatud programmist, kuvatakse see loa küsimisel. See aitab agentide õigusi lahus hoida, kuid ei kaitse teie kasutajakonto all töötava pahatahtliku programmi eest.

Agent saab jälgida teie sisendkausta, kontot või kausta ning saada kirjade muutumise teateid. Ta võib pakkuda ka valmis päringuid „Triage my inbox“ ja „Summarize unread“. Nii jälgimine kui ka päringud järgivad agendile antud õigusi. Sel viisil loetud andmed kajastuvad lugemiste logis.

Sama tuvastatud terminaliprogrammi kaudu käivitatud agendid, näiteks Claude Code, jagavad õigusi. Inbox Classic küsib luba terminalist käivitatud programmidele. Eraldi õiguste andmiseks lisage agendi sätetes argumendi --mcp järele --name ja enda valitud nimi, näiteks "args": ["--mcp", "--name", "Claude Code"]. Seejärel küsitakse luba selle nime all. Nimi ei tõenda programmi identiteeti.

Kõigi agentide juurdepääsu keelamiseks lülitage menüüs Tööriistad > Tehisintellekti agendid valik Luba tehisintellekti agentidel Inbox Classicuga ühenduda välja.
