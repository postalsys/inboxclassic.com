Escriure un missatge

Escriviu i envieu un missatge nou, amb format, enllaços i imatges.

Per escriure un missatge:

  1. Feu clic a Missatge nou, o premeu Ctrl+N. S’obre un missatge nou en una finestra pròpia.
  2. Escriviu les adreces al camp Per a. Separeu les adreces amb comes. Mentre escriviu, Inbox Classic suggereix els contactes, les adreces i els grups que coincideixen amb el text introduït. Premeu Retorn o Tab per seleccionar un suggeriment; si trieu un grup, se n’afegeixen els membres.
  3. Escriviu l’assumpte al camp Assumpte i després el text.
  4. Feu clic a Envia, o premeu Ctrl+Retorn.

Per afegir destinataris en còpia o còpia oculta, feu clic a Cc o Cco al final de la línia dels destinataris. Els destinataris de Cco reben el missatge, però les seves adreces queden ocultes als altres destinataris.

El camp De mostra el compte que s’utilitza per enviar el missatge. Si teniu diversos comptes, hi podeu triar un altre. Llavors el missatge s’envia amb aquell compte i es guarda a la seva carpeta Elements enviats. Per començar des d’un compte concret, feu servir la fletxa del costat del botó Missatge nou.

Si l’assumpte o el text conté una paraula que indica un adjunt, com ara l’anglesa «attached», però no heu adjuntat cap fitxer, Inbox Classic us demana confirmació abans d’enviar el missatge. L’avís només reconeix determinades paraules en anglès, alemany, estonià, castellà i francès.

Per signar digitalment o xifrar el missatge, feu clic a Signa o Xifra a la barra d’eines. Vegeu Signar i xifrar un missatge.

Format

La barra de sobre el text permet triar el tipus de lletra i aplicar negreta, cursiva, subratllat, colors, llistes, sagnat i alineació, així com inserir enllaços, línies divisòries i imatges. Per posar una imatge al text, feu clic a Insereix una imatge o arrossegueu un fitxer d’imatge des de l’Explorador de fitxers fins al text.

Un missatge sense format s’envia com a text sense format, compatible amb tots els programes de correu. Un missatge amb format s’envia com a HTML amb una còpia en text sense format.

Enllaços

Per enllaçar el text seleccionat, feu clic a Hiperenllaç i escriviu l’adreça. Amb el cursor dins d’un enllaç, la barra d’estat mostra l’adreça de destinació. Feu Ctrl+Click en un enllaç web per obrir-lo al navegador. Els enllaços de correu obren un missatge nou. Feu-hi clic amb el botó dret per accedir a Obre l’enllaç, Edita l’enllaç i Elimina l’enllaç.

Les paraules mal escrites queden subratllades. Feu-hi clic amb el botó dret per veure suggeriments.
