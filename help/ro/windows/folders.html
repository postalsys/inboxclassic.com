Lucrul cu folderele

Creați, redenumiți și ștergeți foldere proprii pe serverul de e-mail.

Pentru a crea un folder:

  1. Pentru a crea un subfolder, selectați folderul în care doriți să îl adăugați. Dacă aveți un singur cont și doriți un folder de nivel superior, selectați Mesaje primite sau Semnalizate. Dacă aveți mai multe conturi, faceți clic dreapta pe numele contului dorit.
  2. Alegeți Fișier > Folder > Folder nou sau faceți clic dreapta și alegeți Folder nou.
  3. Introduceți numele și faceți clic pe OK. Cererea de creare este trimisă serverului; folderul apare după confirmare. Inbox Classic vă anunță dacă operația eșuează.

Pentru a redenumi folderul selectat, alegeți Fișier > Folder > Redenumire folder. Pentru a-l șterge, alegeți Fișier > Folder > Ștergere folder. Ambele comenzi se află și în meniul de clic dreapta al folderului.

Ștergerea unui folder șterge mesajele și folderele din el, inclusiv de pe server. Inbox Classic vă întreabă mai întâi.

Mesaje primite și folderele speciale, cum ar fi Elemente trimise, Schițe și Elemente șterse, nu pot fi redenumite sau șterse.

Pentru a deschide un folder fără mouse, alegeți Vizualizare > Salt la folder (Ctrl+Y) și introduceți o parte din numele lui.

Lista de foldere păstrează folderele extinse sau restrânse așa cum le-ați lăsat.
