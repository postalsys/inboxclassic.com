Ansluta en AI-agent

Låt en AI-agent, till exempel Claude, läsa och hantera din e-post via Inbox Classic.

Du kan låta Claude, Cursor eller ett annat program med stöd för Model Context Protocol (MCP) arbeta med din e-post. Inbox Classic har ingen inbyggd AI. Ingen information skickas till en AI-tjänst förrän du ger en agent åtkomst.

Så här ansluter du en agent:

  1. Välj Verktyg > AI-agenter och klicka på Så ansluter du en agent. Inbox Classic visar den konfiguration som du ska lägga till i agentens inställningar.
  2. Lägg till den i agentens inställningar för MCP-servrar. I Claude Desktop öppnar du Settings > Developer > Edit Config.
  3. Starta agenten. När den ansluter första gången får du välja vad den får göra och vilka konton den får komma åt.

Om Inbox Classic inte körs startar agenten det i bakgrunden. Bara program som körs under ditt användarkonto på den här datorn kan ansluta.

Inbox Classic frågar systemet vilket program som startade agenten i stället för att lita på vad agenten säger, så att agenten inte får ett annat programs behörigheter bara genom att uppge dess namn. Om namnen skiljer sig visas det i frågan. Detta håller programmens behörigheter åtskilda, men skyddar inte mot skadlig programvara som redan körs under ditt användarkonto.

En agent kan också bevaka Inkorgen, ett konto eller en mapp och få veta när e-posten där ändras, och den kan erbjuda två färdiga uppdrag, ”Triage my inbox” och ”Summarize unread”. Båda följer det du tillåter agenten, och det den läser på det här sättet visas i dess logg precis som allt annat den läser.

Agenter som du startar från en terminal, till exempel Claude Code, kan räknas som samma program när Inbox Classic identifierar terminalen i startkedjan. Programmet frågar då en gång om program som startats från Terminal, och dessa agenter delar behörigheter. Om du vill ge en agent egen åtkomst lägger du till --name och ett valfritt namn efter --mcp i dess inställningar, till exempel "args": ["--mcp", "--name", "Claude Code"]. Inbox Classic använder då namnet för en separat uppsättning behörigheter. Namnet skapar ingen säkerhetsgräns mot andra program som körs under samma användarkonto.

Om du vill blockera åtkomsten för alla agenter stänger du av inställningen Låt AI-agenter ansluta till Inbox Classic under Verktyg > AI-agenter.
