Inbox Classics nätverksanslutningar

Vart Inbox Classic ansluter och varför, för dig som vill veta mer om tekniken.

  • Dina e-postservrar, via IMAP för att läsa e-post och SMTP för att skicka den. Anslutningarna krypteras med TLS, och varje servers certifikat kontrolleras mot dem som ditt system litar på. Inbox Classic ansluter inte utan kryptering, om du inte väljer Ingen (okrypterad) och bekräftar.
  • När du lägger till ett konto, för att hitta dess servrar. Inbox Classic slår upp domänens MX- och SRV-poster via DNS över HTTPS (Cloudflare, sedan Google), utan att använda vanlig DNS för dessa uppslagningar. Det provar också leverantörens autoconfig-fil och Thunderbirds lista över leverantörer (ISPDB). För Exchange frågar det Microsoft Autodiscover, som bara får ditt lösenord när det ber om det via HTTPS. En server utan kryptering väljs aldrig.
  • Inloggning i webbläsaren, med OAuth 2.0 och PKCE, hos Google, Microsoft eller leverantören av din inloggningsapp. Webbläsaren återvänder bara till Inbox Classic på den här datorn.
  • Varumärkeslogotyper (BIMI), från varumärkets HTTPS-adress när meddelandet inte har med logotypen, med en lokal cache som behålls mellan körningar. Logotyper kan lagras i 30 dagar; misslyckade hämtningar kan försökas igen efter en dag. Det sker bara när din e-postserver har godkänt meddelandets DMARC-kontroll och logotypen.
  • Bilder från internet, när du väljer att visa dem eller har tillåtit dem automatiskt för betrodda avsändare. Skräppost och krypterade meddelandedelar undantas från automatisk hämtning.
  • Avsluta prenumeration, efter din bekräftelse. En direkt begäran (RFC 8058) skickas bara när e-postleverantören har godkänt en DKIM-signatur som omfattar uppgifterna för avregistrering.
  • Krypteringsnycklar, vid nyckelsökning, till exempel när du ska kryptera till någon vars nyckel saknas. Vid adressökning används först adressens domän (Web Key Directory) och sedan keys.openpgp.org om du har tillåtit det. En adress eller nyckelidentifierare skickas, beroende på sökningen.

Engångskoder visas bara när e-postleverantören bekräftar en giltig DKIM-signatur från domänen som koden gäller för eller en överordnad domän. Inbox Classic läser resultatet från leverantörens Authentication-Results- eller ARC-Authentication-Results-fält. Det identifierar inte personen bakom adressen. Själva kodidentifieringen kräver ingen separat anslutning.
