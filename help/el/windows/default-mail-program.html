Ορισμός του Inbox Classic ως προεπιλεγμένης εφαρμογής αλληλογραφίας

Ανοίξτε στο Inbox Classic τους συνδέσμους ηλεκτρονικού ταχυδρομείου και τα αρχεία μηνυμάτων από ιστοσελίδες και άλλα προγράμματα.

Οι σύνδεσμοι ηλεκτρονικού ταχυδρομείου (mailto:) ανοίγουν νέο μήνυμα στην προεπιλεγμένη εφαρμογή αλληλογραφίας σας.

Για να ορίσετε το Inbox Classic ως προεπιλεγμένη εφαρμογή αλληλογραφίας, επιλέξτε Εργαλεία > Ορισμός ως προεπιλεγμένης εφαρμογής αλληλογραφίας. Τα Windows ανοίγουν τις ρυθμίσεις Προεπιλεγμένες εφαρμογές, όπου επιλέγετε το Inbox Classic για τους συνδέσμους MAILTO. Για αυτή τη λειτουργία, το Inbox Classic πρέπει να είναι εγκατεστημένο.

Όταν στη συνέχεια κάνετε κλικ σε έναν σύνδεσμο ηλεκτρονικού ταχυδρομείου, ανοίγει νέο μήνυμα με συμπληρωμένες τις διευθύνσεις, το θέμα και το κείμενο του συνδέσμου. Οι υπόλοιπες παράμετροι του συνδέσμου αγνοούνται.

Αν δεν έχετε ακόμη λογαριασμό, το Inbox Classic σάς ζητά να προσθέσετε πρώτα έναν. Κάντε ξανά κλικ στον σύνδεσμο μόλις προστεθεί.

Αρχεία μηνυμάτων

Για να ανοίγετε αρχεία .eml στο Inbox Classic με διπλό κλικ, πατήστε το κουμπί Άνοιγμα αρχείων .eml με το Inbox Classic στη σελίδα Εργαλεία > Επιλογές > Γενικά. Τα Windows ανοίγουν τις ρυθμίσεις Προεπιλεγμένες εφαρμογές, όπου επιλέγετε το Inbox Classic για τα αρχεία .eml.
