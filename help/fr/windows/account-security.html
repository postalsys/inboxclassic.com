Paramètres de sécurité d'un compte

Les paramètres de sécurité des serveurs d'un compte, et ce que signifie chacun d'eux.

Chaque compte a un paramètre Sécurité IMAP pour le serveur de courrier entrant et un paramètre Sécurité SMTP pour le serveur sortant. Inbox Classic les remplit quand il trouve les paramètres de votre fournisseur. Pour les modifier, ouvrez les propriétés du compte dans Fichier > Comptes.

ParamètreSignification
SSL/TLSLa connexion est chiffrée dès le début. Généralement le port 993 pour le courrier entrant et 465 pour le courrier sortant.
STARTTLSLa connexion est chiffrée juste après son ouverture. Généralement le port 143 pour le courrier entrant et 587 pour le courrier sortant. Inbox Classic s'arrête si le serveur ne propose pas de chiffrement.
Aucune (non chiffrée)Votre mot de passe et votre courrier circulent en clair, lisibles par n'importe qui sur le réseau.
N'utilisez Aucune (non chiffrée) que pour un serveur installé sur votre propre ordinateur ou votre réseau local. Inbox Classic vous avertit avant de l'utiliser.

Inbox Classic vérifie que chaque serveur est bien celui qu'il prétend être, d'après les certificats auxquels votre système fait confiance. Aucun réglage ne permet d'accepter n'importe quel certificat.

Votre mot de passe est conservé dans le Gestionnaire d'identification Windows, jamais dans le stockage du courrier. Un compte qui se connecte via le navigateur ne conserve aucun mot de passe.
