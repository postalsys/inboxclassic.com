Paramètres

Choisissez la langue d’Inbox Classic, réglez l’affichage et les notifications et définissez quels messages télécharger à l’avance.

Ouvrez Outils > Options. Les paramètres sont répartis sur trois pages : Général, Lecture et Téléchargement. Cliquez sur OK pour appliquer vos modifications et fermer la fenêtre, ou sur Appliquer pour les appliquer sans fermer la fenêtre. Annuler abandonne les modifications qui n’ont pas encore été appliquées, y compris celles de la liste des expéditeurs de confiance. Les changements effectués dans les paramètres d’applications par défaut de Windows sont conservés.

Général

  • Langue permet de choisir la langue des fenêtres et de cette aide. Sélectionnez la langue du système ou une autre langue de la liste. Inbox Classic cherche une langue prise en charge dans les préférences du système. S’il n’en trouve aucune, il utilise l’anglais.
  • L’option Me prévenir de l'arrivée de nouveaux messages affiche les notifications de nouveaux messages si la fenêtre principale n’est pas au premier plan et si le système les autorise. Cette option est activée par défaut.
  • L’option Afficher les codes de connexion dans les notifications de nouveau courrier peut afficher les codes à usage unique détectés directement dans les notifications. Cette option est désactivée par défaut, car les notifications peuvent être lues sur un écran verrouillé. Elle n’est disponible que si les notifications sont activées.
  • Délai avant l’envoi définit combien de temps un message reste dans la Boîte d’envoi avant son envoi. Pendant ce délai, vous pouvez annuler l’envoi avec la commande « Annuler ». Le délai par défaut est de 10 secondes.
  • Les boutons Définir comme programme de messagerie par défaut et Ouvrir les fichiers .eml avec Inbox Classic permettent de définir Inbox Classic comme application par défaut pour ouvrir les liens de messagerie et les fichiers de messages. Voir Faire d'Inbox Classic votre application de messagerie.

La nouvelle langue s’applique après un redémarrage d’Inbox Classic. Cliquez sur Redémarrer maintenant pour redémarrer immédiatement, ou sur Plus tard pour utiliser la nouvelle langue au prochain démarrage.

Lecture

  • Disposition permet de choisir la disposition classique, la disposition en colonnes ou l’adaptation automatique à la largeur de la fenêtre. Voir Dispositions.
  • L’option Regrouper les messages par conversation regroupe les messages d’une même conversation sur une seule ligne. Cette option est activée par défaut.
  • L’option Afficher les images des expéditeurs dans la liste des messages affiche les logos de marque ou les photos du Carnet d’adresses dans la disposition en colonnes si le domaine de l’expéditeur est confirmé. À défaut d’image, ses initiales s’affichent. Cette option est activée par défaut.
  • L’option Afficher les pièces jointes dans les messages affiche les images et les premières pages des fichiers PDF après le texte d’un message. L’option est activée par défaut. Désactivez Afficher les fichiers PDF dans les messages pour conserver les images sans afficher les PDF. Voir Pièces jointes.
  • L’option Télécharger les images de tous les messages télécharge automatiquement les images externes de tous les messages, sauf dans le dossier de courrier indésirable. Dans les parties chiffrées d’un message, vous devez autoriser le chargement des images externes à chaque ouverture. Cette option est désactivée par défaut, car les expéditeurs peuvent ainsi savoir quand vous lisez leurs messages. Voir Images et pistage.
  • Le bouton Expéditeurs de confiance ouvre la liste des expéditeurs dont les images sont téléchargées automatiquement lorsque leur domaine est confirmé. Vous pouvez aussi retirer des expéditeurs de cette liste. Le courrier indésirable et les parties chiffrées nécessitent toujours une autorisation distincte.
  • L’option Rechercher dans les messages chiffrés est activée par défaut. Si les clés nécessaires sont disponibles, Inbox Classic déchiffre les messages téléchargés en arrière-plan. Vous pouvez alors rechercher dans leur contenu, et la liste peut afficher un aperçu et l’objet protégé. Le contenu déchiffré est conservé en clair dans l’index local de recherche. Désactiver cette option le retire de l’index. Les agents d’IA n’ont pas accès à ce contenu.
  • L’option Rechercher les clés sur keys.openpgp.org est activée par défaut. Pour une recherche par adresse e-mail, Inbox Classic interroge d’abord le domaine de cette adresse, puis keys.openpgp.org si nécessaire. Le serveur de clés reçoit l’adresse recherchée ou, pour une recherche par empreinte ou identifiant de clé, cet identifiant.

Téléchargement

  • Télécharger les messages à l’avance permet de choisir les messages à télécharger avant leur ouverture. Par défaut, ce sont ceux des 30 derniers jours dont la taille ne dépasse pas 1 Mo. Voir Télécharger les messages à l'avance.
  • Espace maximal par compte limite l’espace des copies locales de contenu, à 1 Go par compte par défaut. Les brouillons et les messages ouverts depuis le lancement sont conservés même si cela dépasse la limite, qui ne s’applique pas à toute la base de données.

La langue choisie lors de la première installation est également enregistrée ici comme langue de l’application.
