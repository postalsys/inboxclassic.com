Répondre et transférer

Répondez à l'expéditeur ou à tout le monde, ou faites suivre un message à quelqu'un d'autre.

  • Répondre (Ctrl+R) répond à l'expéditeur.
  • Répondre à tous (Ctrl+Maj+R) répond à toutes les personnes à qui le message a été envoyé.
  • Transférer (Ctrl+F) fait suivre le message. Vous tapez les destinataires.

Une réponse ou un transfert part du compte où se trouve le message d'origine.

Le message d'origine

Dans une réponse, le message d'origine est replié derrière un bouton ••• sous votre texte, pour que vous ne voyiez que ce que vous écrivez. Il est envoyé avec votre réponse dans tous les cas. Pour le raccourcir, cliquez sur le bouton, ou sélectionnez tout avec Ctrl+A : l'original fait alors partie de votre texte.

Dans un transfert, l'original est dans le texte dès le début, puisque c'est ce que vous envoyez.

Une réponse suit le format de l'original. Une réponse à un message en texte brut est en texte brut, avec l'original cité par des >, sauf si vous mettez quelque chose en forme.

Transférer plusieurs messages

Sélectionnez plusieurs messages et cliquez sur Transférer. Un seul nouveau message est créé, avec tous les messages joints sous forme de fichiers .eml. Son objet est celui du premier message.
