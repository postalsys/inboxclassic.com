Ajouter un indicateur, archiver et déplacer des messages

Ajoutez un indicateur à des messages, marquez-les comme indésirables, archivez-les ou déplacez-les vers un autre dossier, un ou plusieurs à la fois.

Sélectionner plusieurs messages

Utilisez Ctrl+Clic pour ajouter un message à la sélection, ou cliquez sur le premier puis faites Maj+Clic sur le dernier. Édition > Sélectionner tout (Ctrl+A) sélectionne tous les messages de la liste. Les commandes ci-dessous agissent alors sur tous ces messages.

Indicateur

Choisissez Message > Ajouter un indicateur au message pour ajouter un indicateur à un message ou pour le retirer. Pour un indicateur de couleur, choisissez Message > Indicateur et une couleur. Apple Mail affiche les mêmes couleurs. Effacer l'indicateur retire l'indicateur.

Courrier indésirable

Cliquez sur Indésirable, ou appuyez sur Ctrl+J, pour déplacer un message vers Courrier indésirable et signaler à votre serveur de messagerie qu'il est indésirable. Dans Courrier indésirable, Non indésirable le remet dans la Boîte de réception.

Archiver

Cliquez sur Archiver, ou appuyez sur A dans la liste des messages, pour déplacer un message de la Boîte de réception vers Archives. Si le compte n'a pas ce dossier, Inbox Classic le crée. Avec Gmail, l'archivage retire les libellés du message, qui ne reste alors que dans Tous les messages.

Déplacer ou copier

Pour déplacer ou copier des messages vers un dossier :

  1. Cliquez sur les messages avec le bouton droit et choisissez Déplacer vers un dossier ou Copier vers un dossier. Déplacer vers un dossier figure aussi dans le menu Édition (Ctrl+Maj+V).
  2. Choisissez un dossier de n'importe quel compte. Tapez une partie d'un nom pour le trouver. Les derniers dossiers utilisés figurent sous Récents.
  3. Cliquez sur Déplacer ou Copier.

Vous pouvez aussi faire glisser des messages sur un dossier de la liste des dossiers. Maintenez Ctrl en les relâchant pour les copier plutôt que les déplacer. Un message déplacé vers un autre compte n'est retiré de son propre serveur qu'une fois la copie arrivée.

Tout cela se fait aussi sur le serveur, pour que vos autres programmes de messagerie le voient.
