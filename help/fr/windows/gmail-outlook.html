Gmail et Outlook.com

Gmail, Outlook.com et leurs versions professionnelles demandent une connexion via le navigateur ou un mot de passe d'application, jamais votre mot de passe habituel.

Google et Microsoft n'autorisent pas les programmes de messagerie à utiliser votre mot de passe habituel. Vous avez deux possibilités.

Se connecter via le navigateur

Cliquez sur Se connecter avec Google ou Se connecter avec Microsoft dans la fenêtre Ajouter un compte de messagerie. Vous tapez votre mot de passe sur la page même de Google ou de Microsoft : Inbox Classic ne le voit donc jamais. Un tel compte utilise toujours les serveurs de messagerie du fournisseur.

Une organisation Microsoft 365 devra peut-être d'abord autoriser Inbox Classic. Microsoft affiche alors Approbation de l'administrateur nécessaire, et Inbox Classic vous indique l'adresse où votre administrateur peut l'approuver.

Se connecter avec Google est désactivé au départ. Google ne laisse se connecter que les utilisateurs de test d'Inbox Classic tant qu'il n'a pas vérifié l'application. Utilisez un mot de passe d'application, ou votre propre application de connexion (voir Applications de connexion).

Utiliser un mot de passe d'application

  1. Créez un mot de passe d'application dans les paramètres de sécurité de votre compte. Chez Google, il se trouve sous Sécurité > Validation en deux étapes > Mots de passe des applications. Chez Microsoft, sous Sécurité > Options de sécurité avancées > Mots de passe d'application.
  2. Dans la fenêtre Ajouter un compte de messagerie, tapez votre nom et votre adresse, puis cliquez sur Suivant >.
  3. Cliquez sur Utiliser un mot de passe d'application.
  4. Tapez le mot de passe d'application dans Mot de passe, puis cliquez sur Terminer.

Quand la connexion expire

Si Google ou Microsoft met fin à la connexion, Inbox Classic affiche « La connexion au compte … a été refusée ou la session a expiré. » Il vous demande s'il faut vous reconnecter dans le navigateur. Choisissez Oui et connectez-vous de nouveau.
