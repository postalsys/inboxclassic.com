Supprimer des messages et annuler

Supprimez des messages, videz Éléments supprimés et Courrier indésirable, et annulez un déplacement ou une suppression.

Pour supprimer un message, cliquez sur Supprimer, choisissez Édition > Supprimer le message ou appuyez sur Suppr dans la liste des messages. Le message est déplacé vers Éléments supprimés.

Supprimer un message dans Éléments supprimés l'efface définitivement. Inbox Classic demande d'abord confirmation.

Vider un dossier

Un message supprimé définitivement ne peut pas être récupéré, même avec Annuler.

Pour supprimer définitivement tous les messages du dossier Éléments supprimés ou du dossier Courrier indésirable :

  1. Sélectionnez le dossier.
  2. Choisissez Fichier > Dossier > Vider le dossier, ou cliquez sur le dossier avec le bouton droit et choisissez Vider le dossier. Inbox Classic indique combien de messages seront supprimés.
  3. Confirmez pour les supprimer.

Annuler

Édition > Annuler (Ctrl+Z) annule le dernier déplacement, la dernière suppression, le dernier archivage ou le dernier marquage comme indésirable, quel que soit le nombre de messages concernés. Ils retournent dans les dossiers d'où ils venaient, et y sont sélectionnés. Le menu indique ce qu'il annule, par exemple Annuler le déplacement, et la barre d'état indique ce qui a été fait.
