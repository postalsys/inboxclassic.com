Écrire un message

Écrivez et envoyez un nouveau message, avec mise en forme, liens et images.

Pour écrire un message :

  1. Cliquez sur Écrire, ou appuyez sur ⌘N. Un nouveau message s'ouvre dans une fenêtre à part.
  2. Saisissez les adresses dans le champ À. Séparez-les par des virgules. Pendant la saisie, Inbox Classic propose les contacts, adresses et groupes correspondants. Appuyez sur Retour ou Tab pour accepter une proposition ; choisir un groupe ajoute ses membres.
  3. Renseignez le champ Objet, puis rédigez votre message.
  4. Cliquez sur Envoyer, ou appuyez sur ⌘Retour.

Pour ajouter Cc ou Cci, cliquez sur Cc ou Cci au bout de la ligne À. Les personnes en Cci reçoivent le message, mais les autres destinataires ne les voient pas.

Le champ De indique le compte utilisé pour l’envoi. Si vous avez plusieurs comptes, vous pouvez en sélectionner un autre ici. Le message est envoyé depuis ce compte et une copie est enregistrée dans son dossier Éléments envoyés. Pour choisir un compte avant de rédiger, utilisez la flèche à côté du bouton Écrire.

Si l’objet ou le texte contient un mot reconnu comme désignant une pièce jointe, par exemple « ci-joint », mais qu’aucun fichier n’est joint, Inbox Classic vous demande si vous souhaitez quand même envoyer le message.

Pour signer numériquement ou chiffrer le message, cliquez sur Signer ou Chiffrer dans la barre d’outils. Pour en savoir plus, consultez Signer et chiffrer un message.

Mise en forme

La barre au-dessus du texte propose la police, le gras, l'italique, le souligné, la couleur, les listes, le retrait, l'alignement, les liens, une ligne de séparation et les images. Pour placer une image dans le texte, cliquez sur Insérer une image ou faites glisser un fichier image depuis le Finder dans le texte.

Un message sans mise en forme est envoyé en texte brut, lisible par tous les logiciels de messagerie. Un message mis en forme est envoyé en HTML, avec une copie en texte brut.

Liens

Pour créer un lien sur le texte sélectionné, cliquez sur Lien hypertexte et tapez l'adresse. Quand le curseur est dans un lien, la barre d'état indique où il mène. Faites ⌘+Clic sur un lien web pour l’ouvrir dans votre navigateur. Les liens de messagerie ouvrent un nouveau message. Cliquez dessus avec le bouton droit pour choisir Ouvrir le lien, Modifier le lien ou Supprimer le lien.

Les mots mal orthographiés sont soulignés. Cliquez sur l'un d'eux avec le bouton droit pour obtenir des suggestions.
