Conversations

Regroupez les messages d’une même conversation sur une seule ligne et choisissez de surveiller ou d’ignorer la conversation.

Une conversation réduite occupe une ligne. Elle affiche le sujet de la conversation, le nombre de ses messages dans la liste en cours et combien d’entre eux sont nouveaux, comme dans (3, 1 nouveau). L’expéditeur et les premiers mots sont ceux du message qu’elle ouvre : le plus ancien message non lu, ou le plus récent lorsque tous sont lus. Elle est en gras tant qu’un de ses messages est non lu. Les tris par date et par date de réception utilisent son message le plus récent ; les autres tris utilisent son premier message.

Toute la conversation dans le volet de lecture

Sélectionnez la ligne d’une conversation pour lire ses messages ensemble, à partir du plus ancien message non lu, ou du plus récent lorsque tous sont lus. Au départ, les messages non lus et le message de départ sont ouverts ; les autres messages lus sont réduits à une ligne indiquant l’expéditeur, la date et les premiers mots. Cliquez sur une ligne pour ouvrir ce message, et cliquez de nouveau pour le réduire. Vos propres réponses dans Éléments envoyés, vos brouillons et les messages que vous avez classés dans d’autres dossiers sont aussi affichés, chacun avec le nom de son dossier. Les messages de Courrier indésirable et d’Éléments supprimés sont exclus.

  • Répondre, Répondre à tous, Transférer et Imprimer agissent sur le message à la bordure colorée. Ouvrir un message le sélectionne ; le réduire peut sélectionner un autre message ouvert.
  • Les messages non lus affichés ouverts sont marqués comme lus après un instant.
  • Fichier > Imprimer la conversation imprime les messages téléchargés de la conversation, l’un après l’autre. Les messages signés ou chiffrés sont exclus ; ouvrez-les et imprimez-les séparément.
  • Double-cliquez sur la ligne pour ouvrir la conversation dans sa propre fenêtre.
  • Un message signé ou chiffré n’est jamais affiché dans la pile. Sa ligne indique qu’il s’ouvre seul ; cliquez sur la ligne pour le lire séparément.
  • Une longue conversation affiche d’abord ses 20 messages les plus récents, ainsi que les messages plus anciens nécessaires pour inclure le message de départ. Lorsque les messages sont classés du plus ancien au plus récent, cliquez sur le lien pour afficher les messages précédents.

Pour voir un seul message à la fois, désactivez Afficher toute la conversation dans le volet de lecture dans Inbox Classic > Réglages > Lecture. La ligne d’une conversation ouvre alors son plus ancien message non lu, ou son plus récent lorsque tous sont lus. Utilisez Ordre de la conversation, sur la même page, pour choisir d’afficher d’abord les messages les plus anciens ou les plus récents, dans le volet de lecture comme sous la ligne d’une conversation développée.

  • Pour afficher ses messages sous sa ligne, cliquez sur le ▸ devant elle, ou appuyez sur →. Pour les masquer, cliquez sur le ▾, ou appuyez sur ←. Sélectionner l’un des messages sous la ligne affiche ce message seul.
  • Affichage > Développer toutes les conversations et Réduire toutes les conversations font de même pour toute la liste.
  • Lorsque vous supprimez, déplacez, archivez ou marquez une conversation réduite, l’action s’applique à tous ses messages présents dans la liste en cours. Cela concerne aussi le marquage comme lu ou indésirable et l’ajout d’un indicateur. Lorsque la conversation a aussi des messages dans d’autres dossiers, Supprimer, Déplacer et Archiver demandent s’il faut agir sur Ce dossier uniquement ou sur Toute la conversation. Lorsque l’action inclut d’autres dossiers, Archiver et Déplacer laissent les messages envoyés et les brouillons de ces dossiers à leur place.

Pour afficher chaque message sur sa propre ligne, désactivez Regrouper les messages par conversation dans Inbox Classic > Réglages > Lecture.

Surveiller une conversation

Sélectionnez un message et choisissez Message > Surveiller la conversation, ou appuyez sur W dans la liste des messages. Vous recevez aussi des notifications pour les nouveaux messages de cette conversation qui arrivent dans vos propres dossiers. Pour cela, les notifications doivent être activées et la fenêtre principale ne doit pas être au premier plan. Le système doit aussi autoriser les notifications. Les dossiers spéciaux, comme Courrier indésirable et Éléments supprimés, sont exclus. La commande est cochée tant que vous surveillez la conversation.

Ignorer une conversation

Choisissez Message > Ignorer la conversation, ou appuyez sur K dans la liste des messages. La conversation devient grise et est marquée comme lue. Ses nouveaux messages arrivent lus, sans notification. Pour retirer les conversations ignorées de la liste, choisissez Affichage > Masquer les conversations ignorées.

Pour retirer une marque, choisissez de nouveau la même commande. Les deux commandes figurent aussi dans le menu contextuel d'un message.
