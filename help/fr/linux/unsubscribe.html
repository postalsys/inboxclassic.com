Quitter une liste de diffusion

Arrêtez les messages d'une liste de diffusion avec le bouton de désabonnement.

Un message d'une liste de diffusion qui indique comment la quitter affiche Se désabonner à droite de son en-tête.

Pour quitter la liste :

  1. Cliquez sur Se désabonner. Inbox Classic indique ce qui va se passer et demande d'abord confirmation.
  2. Confirmez. Selon la liste, l'une de ces trois choses se produit :
    • Inbox Classic demande à la liste d'arrêter. Aucune page ne s'ouvre et aucun message n'est envoyé.
    • Inbox Classic écrit le message que la liste attend. Cliquez sur Envoyer pour l'envoyer.
    • La page de la liste s'ouvre dans votre navigateur, où vous terminez l'opération.

La barre d'état indique quand la liste a accepté la demande.

Inbox Classic ne demande lui-même à la liste d'arrêter que si le serveur de la liste a signé le message. Un message inventé ne peut donc pas s'en servir pour atteindre quelqu'un d'autre.
