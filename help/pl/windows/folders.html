Praca z folderami

Twórz, zmieniaj nazwy i usuwaj własne foldery na serwerze poczty.

Aby utworzyć folder:

  1. Aby utworzyć podfolder, zaznacz folder nadrzędny. Jeśli masz jedno konto i chcesz utworzyć folder na najwyższym poziomie, zaznacz Skrzynkę odbiorczą lub widok Z flagą. Przy kilku kontach, aby utworzyć go na najwyższym poziomie konta, kliknij zamiast tego prawym przyciskiem myszy nazwę konta.
  2. Wybierz Plik > Folder > Nowy folder albo kliknij prawym przyciskiem myszy i wybierz Nowy folder.
  3. Wpisz nazwę i kliknij OK. Inbox Classic wysyła do serwera żądanie utworzenia folderu i informuje, jeśli się to nie uda.

Aby zmienić nazwę zaznaczonego folderu, wybierz Plik > Folder > Zmień nazwę folderu. Aby go usunąć, wybierz Plik > Folder > Usuń folder. Oba polecenia są też w menu folderu pod prawym przyciskiem myszy.

Usunięcie folderu usuwa zawarte w nim wiadomości i foldery, także na serwerze. Inbox Classic najpierw pyta o zgodę.

Nie można zmienić nazwy ani usunąć Skrzynki odbiorczej i folderów specjalnych, takich jak Elementy wysłane, Wersje robocze i Elementy usunięte.

Aby otworzyć folder bez myszy, wybierz Widok > Przejdź do folderu (Ctrl+Y) i wpisz część jego nazwy.

Program zapamiętuje, które foldery rozwinięto, a które zwinięto.
