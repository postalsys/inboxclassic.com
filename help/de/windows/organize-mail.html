Nachrichten kennzeichnen, archivieren und verschieben

Kennzeichnen Sie Nachrichten, markieren Sie sie als Junk, archivieren Sie sie oder verschieben Sie sie in einen anderen Ordner, einzeln oder mehrere auf einmal.

Mehrere Nachrichten auswählen

Mit Strg+Klick fügen Sie eine Nachricht zur Auswahl hinzu, oder Sie klicken auf die erste und mit Umschalt+Klick auf die letzte. Bearbeiten > Alles auswählen (Strg+A) wählt alle Nachrichten der Liste aus. Die folgenden Befehle wirken dann auf alle.

Kennzeichnen

Wählen Sie Nachricht > Nachricht kennzeichnen, um eine Nachricht zu kennzeichnen oder die Kennzeichnung zu entfernen. Um sie mit einer Farbe zu kennzeichnen, wählen Sie Nachricht > Kennzeichnung und eine Farbe. Apple Mail zeigt dieselben Farben. Kennzeichnung löschen entfernt die Kennzeichnung.

Junk

Klicken Sie auf Junk oder drücken Sie Strg+J, um eine Nachricht in den Ordner Junk-E-Mail zu verschieben und Ihrem Mailserver mitzuteilen, dass sie Junk ist. Im Ordner Junk-E-Mail verschiebt Kein Junk sie zurück in den Posteingang.

Archivieren

Klicken Sie auf Archivieren oder drücken Sie A in der Nachrichtenliste, um eine Nachricht aus dem Posteingang in den Ordner Archiv zu verschieben. Hat das Konto keinen solchen Ordner, legt Inbox Classic ihn an. Bei Gmail entfernt das Archivieren die Labels der Nachricht, sodass sie nur noch in „Alle Nachrichten“ liegt.

Verschieben oder kopieren

So verschieben oder kopieren Sie Nachrichten in einen Ordner:

  1. Klicken Sie mit der rechten Maustaste auf die Nachrichten und wählen Sie In Ordner verschieben oder In Ordner kopieren. In Ordner verschieben steht auch im Menü Bearbeiten (Strg+Umschalt+V).
  2. Wählen Sie einen Ordner eines beliebigen Kontos. Geben Sie einen Teil eines Namens ein, um ihn zu finden. Die zuletzt verwendeten Ordner stehen unter Zuletzt verwendet.
  3. Klicken Sie auf Verschieben oder Kopieren.

Sie können Nachrichten auch auf einen Ordner in der Ordnerliste ziehen. Halten Sie beim Loslassen Strg gedrückt, um sie stattdessen zu kopieren. Eine in ein anderes Konto verschobene Nachricht wird erst von ihrem eigenen Server entfernt, wenn die Kopie angekommen ist.

All das geschieht auch auf dem Server, sodass Ihre anderen E-Mail-Programme es ebenfalls sehen.
