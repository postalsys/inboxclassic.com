Neue Nachrichten mit Regeln sortieren

Lassen Sie eingehende Nachrichten nach Ihren Kriterien automatisch verschieben, als gelesen markieren, kennzeichnen oder archivieren.

Eine Regel besteht aus Suchkriterien und Aktionen, die auf passende Nachrichten beim Eintreffen im Posteingang angewendet werden. Eine Regel mit from:news@example.com kann zum Beispiel Newsletter von dieser Adresse in einen eigenen Ordner verschieben und als gelesen markieren.

So erstellen Sie eine Regel:

  1. Wählen Sie Extras > Nachrichtenregeln und klicken Sie auf Neu.
  2. Geben Sie einen Namen ein und tragen Sie unter Suchkriterien dieselben Suchbegriffe wie im Suchfeld ein, etwa mit from:, subject: oder list:. Die Zeile darunter zeigt, wie viele vorhandene Nachrichten im Posteingang diesen Kriterien entsprechen.
  3. Wählen Sie eine oder mehrere Aktionen für passende Nachrichten: in einen Ordner verschieben, als gelesen markieren, kennzeichnen, archivieren, in Junk-E-Mail verschieben, löschen oder Benachrichtigungen unterdrücken.
  4. Klicken Sie auf OK.

Sie können eine Regel auch aus einer Nachricht oder einer Suche erstellen. Mit Nachricht > Regel aus Nachricht erstellen wird der Absender oder die Mailingliste der ausgewählten Nachricht übernommen. Mit Regel erstellen über den Suchergebnissen übernehmen Sie die aktuellen Suchkriterien.

So funktionieren Regeln

Regeln verarbeiten neue Nachrichten im Posteingang, solange Inbox Classic geöffnet ist, auch im Hintergrund. Vorhandene Nachrichten werden nur einbezogen, wenn Sie die Option Auch auf die Nachrichten anwenden, die schon im Posteingang sind aktivieren. Passende Regeln werden in der Reihenfolge der Liste angewendet. Sobald eine passende Regel eine gültige Verschiebeaktion plant, werden keine weiteren Regeln geprüft, noch bevor der Server die Aktion bestätigt. Deaktivieren Sie das Kontrollkästchen einer Regel in der Liste, um sie auszuschalten, ohne sie zu löschen.

Regeln ändern

Um eine Regel zu bearbeiten, wählen Sie sie in der Liste aus und klicken Sie auf Bearbeiten, oder doppelklicken Sie darauf. Mit Nach oben und Nach unten ändern Sie die Reihenfolge. Mit Löschen löschen Sie die Regel. Im Regeleditor öffnet Anzeigen im Hauptfenster eine Suche in allen Posteingängen. Die Kontoauswahl für die Trefferzahl wird dabei nicht übernommen. Der Editor schließt sich, ohne ungespeicherte Änderungen zu übernehmen.

Regeln gelten für neu eingehende Nachrichten im Posteingang. Filter nach Ordner oder Datum werden daher nicht unterstützt. Wenn Sie in:, before:, after:, older_than: oder newer_than: verwenden, erscheint ein Hinweis mit der Begründung. Regeln können keine Nachrichten senden oder endgültig löschen: Löschen verschiebt sie nach Gelöschte Objekte, sofern dieser Ordner vorhanden ist. Fehlt er, werden Nachrichten durch die Regel nicht endgültig gelöscht.

Regeln werden auf diesem Computer ausgeführt. Um Nachrichten auch bei ausgeschaltetem Computer zu sortieren, verwenden Sie die Filter Ihres E-Mail-Anbieters.
