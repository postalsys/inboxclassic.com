Gmail і Outlook.com

У Gmail можна ввійти через браузер або за допомогою пароля застосунку; в Outlook.com і Microsoft 365 лише через браузер.

Google і Microsoft не дозволяють поштовим програмам використовувати ваш звичайний пароль. Для Gmail є два способи входу, а для Outlook.com і Microsoft 365 лише вхід через браузер.

Вхід через браузер

Клацніть Увійти через Google або Увійти через Microsoft у вікні Додати поштовий обліковий запис. Ви вводите пароль на сторінці самого Google чи Microsoft, тому Inbox Classic його ніколи не бачить. Такий обліковий запис завжди використовує власні поштові сервери провайдера.

У Microsoft 365 спочатку може знадобитися дозвіл адміністратора організації на використання Inbox Classic. Тоді Microsoft показує Need admin approval, а Inbox Classic повідомляє адресу, за якою ваш адміністратор це схвалює.

Увійти через Google спочатку вимкнено. У цій конфігурації вбудований клієнт призначений для тестових користувачів; вимкнена кнопка не свідчить про поточний стан перевірки Google. Використайте пароль застосунку, якщо обліковий запис це дозволяє, або власний застосунок для входу (див. Застосунки для входу).

Пароль застосунку

Цей спосіб доступний для Gmail, якщо у вашому обліковому записі Google ввімкнено двоетапну перевірку та дозволено створювати паролі застосунків.

  1. Створіть пароль застосунку в обліковому записі Google: Безпека > Двоетапна перевірка > Паролі додатків.
  2. У вікні Додати поштовий обліковий запис введіть своє ім’я та адресу й клацніть Далі.
  3. Клацніть Використати пароль застосунку.
  4. Введіть пароль застосунку в поле Пароль, а тоді клацніть Готово.

Коли сеанс входу завершується

Якщо Google чи Microsoft завершує сеанс, Inbox Classic повідомляє, що вхід відхилено або термін дії сеансу минув. Програма пропонує ввійти знову через браузер. Виберіть Так й увійдіть ще раз.
