Fjern Inbox Classic

Fjern Inbox Classic fra datamaskinen, med eller uten de lokale dataene.

Fjern pakken med sudo apt remove inbox-classic, eller med sudo pacman -R inbox-classic på Arch Linux og Omarchy. Lokale data ligger som standard i ~/.local/share/inbox-classic til du sletter også den mappen.

Avinstallering fjerner ikke e-posten på serverne dine. Passord og andre hemmeligheter i systemets separate lagring blir heller ikke slettet bare fordi du fjerner programmet eller datamappen.

Fjern først hver konto i Fil > Kontoer for å fjerne de lagrede påloggingsopplysningene. Se Endre, ordne og fjern kontoer for å fjerne bare én konto.
