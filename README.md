# inboxclassic.com

The homepage of Inbox Classic, served by GitHub Pages from `main` at https://inboxclassic.com (`CNAME`). A single static page, `index.html`; the screenshots in `img/` come from the app's UI end-to-end test (`build/ui-e2e`), cropped to the window.

Format with `npx prettier --write index.html`.
